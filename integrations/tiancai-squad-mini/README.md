# 天才小分队微信小程序站点补丁

本目录向现有站点增加个人资料的「微信小程序」绑定码，以及账户查看和个人充值所需的窄接口。完整站点保留在维护方自己的仓库。

在站点源码检出上运行 `python apply.py <站点根目录>` 检查基线与补丁目标。核对无误后，使用 `--apply` 写入同一检出。每个被修改的原文件生成独立的 `.before-mini` 备份。之后按站点现有流程构建后端和前端，迁移沿用原有支付订单与 Redis 设施。站点和云服务均配置至少 32 字符的 `SQUAD_BRIDGE_SECRET`，通过 HTTPS 转发服务端请求。该密钥属于站点及其统一运营的中转服务，勿发给小程序客户端。

用户先通过站点原登录流程，在个人资料生成 3 分钟有效的一次性短码，再到手机兑换。站点临时绑定有效期 90 天。账户停用、凭据指纹变更或绑定到期后需重新绑定。手机仅获得本服务的微信登录令牌。站点可通过 Redis 按对应绑定键撤销，配置密钥撤销后中转服务失去业务访问权。

站点沿用现有用户余额、可见公告、七日个人实际扣费、充值限额、手续费和优惠报价。创建余额订单时使用唯一的小程序商家单号，站点已有的订单状态、支付金额检查、账户入账与重复通知保护继续适用。远程设备授权不授予站点接口权限。

回退前先核对尚未到账的微信订单，在确认全部入账后关闭小程序充值。还原原文件并删除此补丁新加的三个业务源码文件，重新构建站点。历史已支付订单及到账记录保留在原站点账本。

本批将补丁实际应用到参考站点的隔离副本。七个目标文件全部应用成功。Go 1.27.2 在打好补丁的后端运行 `go build -p 3 -mod=readonly ./internal/server/routes` 通过，覆盖账户绑定、站点查询与余额订单相关的路由、处理器及服务。Vue 3.5.43 单文件组件编译器通过了修改后的个人资料页和新绑定码组件的脚本与模板编译。生产站点、微信和实际扣款待部署方验收。
