## 本轮行为

| 反馈 | 本轮实现 |
| --- | --- |
| 真实调用不显示模型和渠道 | 不再因客户端未识别而丢弃已解析路由；此时展示Hub→模型→渠道。专用URL、受管配置与普通Codex请求头提供归属证据，不按模型名称借用客户端身份 |
| 运行刷新慢 | 概览每300毫秒请求`/api/desktop/activity?live=true`，不等待远控、天工桥或IM状态；完整客户端概览仍用原接口。两种结果中的端内请求与根请求使用同一最新快照 |
| 图标与展开收起 | 原三端复用仓库品牌线图，新端采用对应透明品牌图；三点按钮增大点击区域，收起带双折叠图标，稳定三端位置规则不变 |
| 客户端资源混入全局库 | 默认“使用中”仅含本端已使用及需核对的受管配置；“可添加”仅兼容内容。全局页仍管理全部资源。多配置位置明确标注，不影响原真实写入/读回/撤销 |
| 列表和详情不合适 | 改为1–3列自适应卡片，卡片内直接使用/停用、编辑与配置位置；全局显示客户端小块，本端只显示本端操作 |
| 厂商输入文字挤压 | 共用输入框最低高度取原生字体度量加12 DIP内边距且至少36 DIP；单行原生编辑器垂直居中，厂商六字段布局共用`ProviderFields`，不接受旧30物理像素限制 |
| 日志窄、客户端未知 | 普通列按可用宽度重新分配，表格占满正文；技术列继续横向滚动。深色下技术列开关、附加条件与分页文字使用主题前景色。新请求按来源证据记录，旧行没存的来源保留“未标记来源”，不修改或猜测原日志 |
| 统计选择与悬浮 | 模型/渠道从当前日期与客户端范围的全部历史值选择，不取第一页或前50名，不因已选值而只剩一个选项；“查看请求”固定短按钮。曲线按实际点位悬浮显示时段、请求、输入与输出，缺失用量仍未报告 |

活动依赖正在经过Hub的真实请求，响应体结束或取消即移除；等待超过5秒停止流动。300毫秒是轮询间隔而非逐帧事件保证，极短请求可能在两次读取之间结束，原日志仍记录。无请求但客户端已打开时保留该端；没有打开端或在途请求才仅Hub。关闭日志记录不关闭活动观测。

维护代码：`src/desktop/activity.rs`、`activity/tests.rs`、`runtime.rs`、`resources.rs`，`src/ai_gateway/{context,handler}.rs`、`request_log/desktop.rs`，`src/web/desktop.rs`及`src/gui/{overview,visual,controls,shell,resources,resource_gallery,provider_form,request_view,request_browser,usage_view}.rs`。生产布局由独立隐藏检查复用，避免用重新拼装的网页当作程序效果。vendor仅补原生长标题省略样式枚举，现行wxWidgets值保持；代码/对象类型边界见[主题](../gui-theme.zh-CN.md)。

新增API仅为兼容查询参数`live=true`、统计响应`filters.models/channels`、资源目标响应`managed/compatible`；原请求/保存接口和持久配置格式保持。客户端专用路由、独立副本、来源同步、revision、文件锁、备份、原子替换和后改保护保持。日志输入/输出、缓存和首字原明细不改，不回填历史来源。不迁移数据，回滚界面须连同对应Rust共用层/vendor补丁整体处理；安装降级规则见[指南](../v1-desktop-guide.zh-CN.md)。

唯一`main`，HEAD `25d024b2baa6af25f66bd69d5b237e0caa35df80`加既有未提交开发。Cargo/lock为1.0.3；EXE数字版本1.0.3.0、MSI ProductVersion1.0.3，UpgradeCode保持`{42B4BF3C-E660-4C83-96AA-56A4426B96A2}`。未读取或修改`zhenduan/`、`docs/.obsidian/`；未启动实际Hub、客户端、IDE或安装器，未作真实模型/MCP、站点登录或支付调用；未提交、推送、Actions或发布。

## 验证与待验收

最终证据统一放`target/v1.0.3-runtime-polish-20261108/`。隐藏原生布局覆盖生产Shell/UsageView/ClientHeader、厂商六字段、资源卡片和日志页；使用合成数据，不调用产品初始化或用户配置。字体10/13/15/20pt度量检查不等于实际125/150/200%系统DPI。独立绘图另查多端多路由、未知调用方以及节点命中区域。离线合成HTTP用例通过真实嵌套路由、中间件、协议处理和SSE响应体观察活动/日志，均使用临时配置与回环合成服务。

本机不原生构建或实测macOS；真实客户端刷新/重启、请求归属、资源使用、输入法、窗口缩放及实际外观由用户安装验收。WorkBuddy `/wb`外部执行仍未接通，Codex持续EBADF根因仍未确认，不扩大本轮修复范围。

首轮完整回归为1157通过、1失败、5 ignored，95.68秒；失败为125%下首个曲线点的物理像素取整边界，已改为与绘图相同的整数逻辑尺寸/取整及1物理像素邻界。原构建、回归与合成图记录保留在`before-dpi-fix-*`，不作为最终包凭据、不累加测试数量；修正后重新构建并完整重跑。测试子进程单独使用隔离HOME/USERPROFILE/AppData与客户端配置路径，不改变开发shell或真实程序环境。

随后人工检查发现深色日志页的技术列开关/分页文字对比度不足，已补主题前景色，同时让独立合成图的版本取自Cargo。此前通过的中间结果保留在`before-contrast-fix-*`，最终源再次构建、完整回归和生成新图，不将中间结果充当最终包证据。
