## 本轮行为

- 页签及本页对话框改为 Dumpling-MCP；帮助菜单“显示 Dumpling-MCP”控制显示，主配置 `showDumplingMcp=false` 为默认。勾选即时显示/选中并保存，取消勾选隐藏且保留表单/后台连接；首次显示读取状态，已有快照重显保留内容，可手动刷新。图标为内嵌透明线条 SVG，保留 Hub 品牌饺子、轨道和箭头意象，随主题着色。
- Codex MCP 名称采用已保存环境名称，如 `MCP196`，Hub 支持 1～64 位英文字母、数字、`-`、`_`。检查/移除/恢复使用实际受管名；旧哈希或旧环境名通过更新接入迁移，一次文件替换删旧添新，预览/保护备份/journal/补偿核对完整旧新目标；目标占用或外部修改拒绝覆盖。保留原 v1 ledger/备份读取，新 Codex version 2 定向备份需新包管理，回退前用新包移除/恢复。WorkBuddy/天工命名不变。
- 三端“检查、检测本机桥、预览接入、移除、恢复”增加简短悬浮说明。当前可用工具来自实际 MCP 的 initialize/分页 tools/list，显示返回 title/annotations.title 或 description 短简介、原代码及有界说明，缺中文明确提示、不猜译，读取工具目录不代表执行成功。
- Windows 关机/注销 query 明确放行，不走普通 × 的 veto/托盘提示，系统取消结束会话不改变运行状态；确认 end-session 非阻塞尽力清理自有后台/计时器/托盘，普通 × 隐藏和菜单退出保留。wxDragon 增加窄 App session 事件桥，macOS 原生待 Actions/验收。
- Windows MSI 新装/major upgrade 完整交互安装成功页提供“打开 TianCaiSpaceHub”或“完成”；只有主动点打开才以非提升用户权限启动。静默、失败、卸载、修复不显示该成功页或自动启动。UI/Util 扩展与 WiX 锁定版本，当前只静态核对，实际 MSI 生成/安装待 GitHub Actions/用户。

- 服务方式勾选“保存应用密钥”并点击“保存环境”，立即交给 DPAPI/Keychain，不依赖登录成功；密码仍仅成功后记住。非空保存/替换，空输入仅复用完全未改环境中可读取的原引用，改字段/无引用/不可读时要求重填；显式新密钥可替换不可读旧记录。取消勾选并保存移除原密钥。加载有引用的环境恢复勾选和保存状态，API 不返回/回填秘密；顶层 `rememberSecret/clientSecret` 不写 profile，旧 API 不带选项保持原语义。未改旧 null 机构/认证头和默认 MCP 表示保留。配置失败清新 blob，成功后清旧引用，字段/引用变化撤销旧授权、保存不自动登录；提交后错误及跨存储边界见专题。
- 新 `TokenExpiryPolicy` 区分 `Unknown/Fixed/SlidingIdle`。password 个人/MCP 两份 token 为闲置策略、初次准确到期为空，默认闲置 30 分钟且正常认证访问更新会话；Hub 不用初次登录时间硬判或本机推算 touch。换票 token 固定默认 24 小时、调用不延长，应用 `tokenValidTime` 可覆盖。准确期限优先自身 `expiresAtMs`，否则自身服务 `createTime`（毫秒）加正 `validTime/tokenValidTime`（秒），缺有效正时长或 0 用 86400 秒；缺创建时间保留未知，不造本机期限，不继承 apply ticket 600 秒。UI/中英帮助显示规则或 UTC 到期+剩余时间。
- 系统保护快照保存 `expiryPolicy`，管理状态返回两份策略；恢复旧快照按已核对模式清除 password 旧非零硬期限、保留真实 401 零失效标记，browser/application 保留原期限、不按恢复时间补 24 小时。普通配置 schema 仍 v1，指纹、身份恢复核验、代次及不重放保护保持。显式登录 401 区分取票、换票及读取账号租户；恢复/运行核验仍固定安全错误。服务规则由用户补充，本版未做真实期限实测，不能宣称真实 401 已消除。
- Hub 独立 Dumpling-MCP 页签的认证选项为“账号密码”和“认证服务连接”，新环境仍默认账号密码。主动切入认证服务连接默认勾选“使用共享应用代表指定用户”，主区填写代表账号、`ClientID`、`ClientSecret`；取消勾选保留浏览器个人授权流程。既有 password/browser/application 环境保持实际认证模式，不因改标签而转换。连接说明改为“在认证服务管理添加应用服务，获取ClientID和ClientSecret”；签名参数仍在高级设置，密码登录不显示应用字段。
- 右上角新增 `?` 配置说明按钮，点击打开原生帮助对话框，说明环境地址、应用服务申请、两条服务认证链路、密码登录、凭据保存、MCP 检测与各端接入。去除认证切换常驻文案、应用代表用户横幅与高级默认说明，把步骤集中到帮助；实际错误与认证状态保留。
- 普通登录只需一个 NVWA 服务地址。独立认证地址、MCP 路径或地址、租户和机构在折叠高级设置；MCP 默认直接显示 `/mcp`，可改其他路径或完整 HTTP(S) 地址。路径保留部署前缀并随服务地址变化，完整 URL 作为固定覆盖。
- 主认证下拉切换清除旧账号、凭据、应用 ID、验证与检测状态；共享复选框切换保留 ClientID、ClientSecret 和保存密钥选项，其他旧输入/状态清理。两者都取消旧授权并使迟到结果失效，通用地址保留。密码与 ClientSecret 按用户要求直接可见，登录加密、保存及日志规则不变。保存后仅在完整环境一致时保留内存秘密、不写普通配置；双因子仅在挑战时显示，验证码图片未实现。密码登录使用原始 `Authorization`，换票使用 `authorization-ticket-token`，有效期分别记录。
- `__default_tenant__` 是用户确认的有效默认租户，本轮取消之前误将返回值当作占位而拒绝的逻辑。仍只取返回的非空上下文租户、优先 `tenantName`/回退 `tenantId`，保持显式账号/租户匹配，不从表单补造身份。显示当前账号及返回租户，默认值显示“默认租户（__default_tenant__）”。
- 独立本机 HTTP 桥默认监听 `127.0.0.1:3849`，用每环境、每客户端凭据隔离权限，绑定实际用户、稳定身份、租户和认证代次，映射上游请求 ID，退出/重新登录撤销旧访问。响应和未知业务结果保留，不自动重放工具请求。
- GUI 常见登录/检测提示、身份/有效期、确认主内容和帮助有中英；适配器说明仍中文，未知后端错误保留固定安全文本，未做全量国际化或统一错误码。接入预览先检查登录，移除/恢复可未登录；确认说明环境、客户端、实际 MCP 名称、文件或天工设置及操作后果，Codex 更新迁移另显示旧名→新名。工具清单与配置保存不承诺实际调用通过；仍需客户端刷新/信任及用户验收。重新登录先清旧快照/工具清单/客户端检测，等待浏览器/双因子/改密时不沿用旧“已登录”账号，成功后重读真实状态。
- Codex、WorkBuddy 只修改受管 MCP 项；天工只走已核验官方桌面 DataServer 的 connection 接口。操作先预览再按指纹写入，备份目标前像并保护秘密，拒绝覆盖同名非受管项目或用户改动。
- 普通环境独立保存，密码/应用密钥默认不记住；Windows 使用用户域 DPAPI，macOS 使用 Keychain，无明文降级。重启恢复后必须重新核验身份。

本轮新增验收为帮助菜单默认隐藏/保存显示、隐藏后重显保留表单与后台连接、透明品牌图标、五按钮悬浮说明与工具中文字段/无中文提示；Codex `MCP196` 原样接入、旧 hash/旧环境名迁移、路径别名、同名冲突/外改拒绝、移除/恢复/崩溃保护及 v1/v2 备份边界。Windows 关机/注销放行、取消关机继续运行、普通 × 隐藏、后台正在启动时结束会话，以及 Actions MSI 新装/升级成功页“打开/完成”、静默/卸载/修复/失败不启动与权限/DPI行为仍待用户验收。开发方仅编译和静态核对。

此前未登录保存/替换/空复用/取消移除应用密钥、旧 null/default 字段保留、不可读记录显式替换、配置冲突清理与提交后错误边界、已保存状态不回填秘密和引用变化撤销旧授权；密码连续认证访问/闲置失效、换票固定默认/应用覆盖与 UTC 显示、缺时间不造期限、旧快照迁移/真实401标记及真实失败步骤等仍保留待验收状态。默认租户、账号/返回租户、旧已登录清理、中英提示/确认/帮助、预览、共享资料保留及可见输入同样保留。适配器中文和恢复路径固定安全文本属于已注明边界，不宣称全量国际化或真实 401 已解决。

认证服务连接默认共享、`ClientID`/`ClientSecret` 和帮助阅读、取消共享的浏览器链路及旧环境原模式；单服务地址默认与自定义部署覆盖、认证切换清空/取消迟到、保存后凭据保留和并发修改保护；账号密码成功/错误/锁定、RSA/SM2、图形验证码受限提示与双因子按需显示、身份/租户核对、两类 token 期限和过期行为；浏览器回环 URL/端口/白名单及 ticket 完整兑换；三端原生加载/信任/调用、重启和跨身份隔离、配置冲突/恢复/未知结果，以及 Windows/macOS 安装升级。当前仅支持所核对的 stateless JSON MCP；上游 SSE 或远端 session 请求明确拒绝，不能将未支持协议视为已连接。
