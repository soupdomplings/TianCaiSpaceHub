**测试包**：`target/TianCaiSpaceHub-v1.0.51-test-20261119-185942-windows-x64.msi`，29,511,680 字节。SHA-256：`d95ebe92800f9a6656027218bfb330f2e07fb8375aa863147b402223de606000`。Windows release 构建通过，已核验 MSI 1.0.51、EXE 1.0.51.0、升级规则及五个内嵌文件。19 项定向 Rust 测试与 11 项 Python 脚本用例通过，包括合成文件框、读取已装 Xshell 的静态菜单资源、策略迁移和 MCP 表单往返。没有安装该包或操作真实 SSH 会话。

**建议验收**：

1. 升级后重开使用 XshellB-MCP 的 Agent 客户端。在 Hub 的「共用能力 → XshellB-MCP」查看本机已接入的标签；如果目标还标着旧脚本，在那个 Xshell 标签选择「工具 → 脚本 → 取消」。已有其他脚本时先核对用途，不需要断开 SSH。
2. 选定已登录且停在空闲提示符的 Xshell 标签，在 Hub 选对应窗口，点一次「启动脚本」。应直接显示「已接入所选标签页」，不需自己选文件。没有弹窗仍失败时，记录新的完整提示以及该标签「运行」「取消」哪一个可用。
3. 在「设置巡检权限」里把当前目录设为自动同意，磁盘用量保留每次询问。让 Agent 分别查看当前目录和磁盘用量。支持表单的客户端应只在第二项询问，拒绝后不应执行或再弹 Xshell 窗口。不支持表单的客户端会在 Xshell 中询问。
4. 把另一条命令（如 `date`）从「不提供」改为「自动同意」再测试。若客户端缓存了工具列表，重开对话或客户端再试。

目前仅提供列出的只读巡检。真实终端上启动脚本、Agent 实际展示表单和交互效果待用户验收。
