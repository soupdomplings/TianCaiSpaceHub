## 范围与实现

- 天才搭档修复消息正文截住鼠标滚轮，复用系统原生滚动规则；Markdown 渲染标题、列表、代码与表格，窄框表格改字段行，流式更新保留已完成文字及选区，默认简短回复。
- 正常原生状态 `error: null` 不再误判失败。模型从已启用来源解析，未知或前缀歧义先选择，新增上游 ID 需要实际来源目录证明；渠道保存不代表完成客户端配置。写入后回读实际副本、条目和启用状态才报告成功。见 [搭档专题](../customizations/genius-buddy.md)。
- Codex 模型页响应实际保存结果；有未保存草稿时保留并提示，点击“载入更新”立即更新勾选。无语义变化的远端排序同步保存基准，避免误报冲突。
- 五个可见客户端全部展示，移除最近槽、更多和收起。菜单选中增加颜色过渡，搭档展开收起增加短位移，可中途反向并遵守减少动画设置。见 [桌面视觉](../development/desktop-visual-system.md)。
- 小分队导入重构为模型搜索多选、真实客户端目标选择、固定操作区与三列结果表。来源只保存一次，逐项使用最新 revision 调用原生接口，保留成功项，不重放未知写入。账户、密钥、通知、充值、发票、组织等弹窗统一卡片与滚动，原金额、权限、报价和并发语义保留。见 [账户](../customizations/tiancai-squad-account.md) 与 [导入](../hub-external-import.md)。
- 天工增强启动显示页头准备状态及具体失败，`Unverified` 不再当作增强就绪。ZCode 在真实可用的 Hub 外部副本存在时适配免官方登录启动，仅内存调整启动入口，不伪造账号、不改安装资源。见 [天工](../customizations/gmclaw.md) 与 [客户端](../customizations/desktop-client-adapters.md)。
- MiniMax 补充官方 OpenAI 兼容地址及按量/Coding Plan Key 区别，不增加没有请求差异的套餐开关。见 [厂商说明](../customizations/desktop-capability-management.md)。

## 验证边界

代码确认 WorkBuddy/天工成功状态含 `error: null`，旧桥接以字段存在判错；缺少用户当次工具轨迹，不能断言原回复只由此造成。当前机器只读检查发现 Hub 有一个启用天工外部渠道，而原生数据库没有对应受管行，因此增强预检会在启动前拒绝；已补可见说明，没有修改用户原配置，也没有把真实启动计为通过。

新隔离测试首次使用含 crate 前缀的 exact 子用例名称，实际执行零项却返回成功；已纠正名称并检查实际执行数。该次空执行、GUI 子系统异步返回的空日志不计为通过。原生滚动/动画夹具修正首显空白与延迟销毁时机，屏幕检查以正常显示的隔离窗口执行；导入夹具的长模型仍遵守原 256 字节限制。结果表检查另定位并修复 vendor `ListCtrl::get_item_text` 未分配 UTF-8 终止位导致中文回读截尾，最终以实际补验结果为准。
