## 用户验收

1. 安装后确认 Hub 为 `0.4.30-8`，天工显示“天工 Work 接入”。两页字段、按钮、长内容滚动、浅色/深色及三页只读底色符合预期；WorkBuddy 思考强度和保存/删除/撤销功能正常。
2. 在新 Work 和仍使用旧天工的机器分别保存模型；确认原默认状态保留，独立模型/渠道及原有其他条目未被影响。
3. IM 选择非首项模型新建任务，回复后在天工打开同一任务继续，确认使用同一模型；桌面更换模型后 IM 应要求重新恢复，而不是沿用旧选择。已有历史空绑定任务恢复后同样核对。
4. 验证普通问答、主工具批准/拒绝、过期审批、任务仍在收尾及断流场景；未知状态不应重复执行。子任务审批继续在天工处理。
5. 使用需要多轮工具的流式模型，确认中文、工具 ID 和推理上下文；运行/重连/排队时 Hub 不抢写桌面草稿或消息，空闲后局部同步。
6. Dumpling-MCP 分别检查三端已有连接、环境名、登录续认证及工具刷新/调用。本轮未改变认证链路，实际行为仍需用户验证。

macOS 需要原生构建及相同范围实机验收；Windows 隔离通过不能作为 Mac 已验收证据。旧 API 缺少新能力仍沿原行为，有新字段但形状不兼容时只停止相应操作。原生任务模型 API 无 CAS，外部并发切换仍不能保证原子一致；流式状态严格前缀匹配，不保证跨裁剪、系统提示变化或重启恢复。
