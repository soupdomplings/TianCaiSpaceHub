## 本轮修复

- 去掉左上“天才空间”大标题及品牌副标题，仅留小图标/短品牌；侧栏202 DIP、品牌区50 DIP、顶栏38 DIP、内容边距18 DIP。运行页移除重复左侧菜单的聊天/Skill/MCP三个长条。
- 使用统计的无标签长输入改为短筛选工具栏，模型/渠道在带标签的弹窗填写；条件数量可见并可直接清除。四卡76 DIP、整体最大宽1000 DIP；趋势改水平切线Bézier，缺失报告断开、不伪造零。统计表圆角无外框、去网格、列宽随窗口分配。保留原日期/客户端/route筛选和请求下钻。
- 共用按钮、选择、输入和卡片同步到新旧客户端、厂商来源、资源、账户及维护窗口。闭合选择框浅边圆角，菜单及wxChoice事件仍原生；输入框内仍是真正wxTextCtrl，保留密码、多行、只读、中文输入和文本事件。程序设置选择静默，用户选择才触发原回调。
- 深色原生表头同步列表字体/颜色，修复白底黑字条；错误文字设置换行上限。另有浅深两张共用字段控件画廊，检查密码、多行和选择外观，不冒充具体业务页面。
- ScrolledWindow改8 DIP轨道/4 DIP圆角滑块，溢出才显示，保留原滚轮、键盘、焦点和虚拟尺寸逻辑；修复隐藏系统bar后短窗压扁图表的问题。说明文字随父宽度重新换行，资源详情/客户端设置可滚动。
- 七端右上启动、下方重新读取。Codex增强启动、WB/天工桌面启动与重新读取沿原模块的预检查、确认、禁用、错误和恢复路径；新四端保留原open API，不把入口移动当成新增启动能力。

实现、vendor类型边界及整体回滚见 [主题](../gui-theme.zh-CN.md)、[V1实施](../development/v1-implementation.md)，操作见 [指南](../v1-desktop-guide.zh-CN.md)。继续Rust + vendor wxDragon/wxWidgets，没有迁移Web主界面，也不承诺每个旧对话框与HTML逐像素一致。

## 验证方法与边界

[desktop_layout_review.rs](../../examples/desktop_layout_review.rs)直接使用生产Shell、UsageView、ClientHeader、选择/输入和绘图层，构造隐藏原生组件并捕获其控件树。统计检查1366×900、960×640、1920×1080和深色；七端核对启动在读取上方；检查程序/键盘选择、禁用、文本事件、销毁、虚拟尺寸及滚轮。不调用Hub初始化、API、用户配置，不显示窗口或进入应用事件循环。

PNG为**合成数据的隐藏生产组件布局捕获**，仍不是实际Hub运行截图；实际主窗菜单/托盘、业务数据、IME交互、滚动条拖动/触控、多显示器及125/150/200%实机缩放待用户验收。本机DPI为100%，旧独立绘图的150%比例检查不等于实际多屏DPI测试。macOS捕获返回空，本机不声称macOS构建或外观通过。

旧[desktop_visual_review.rs](../../examples/desktop_visual_review.rs)继续用于多端多路由、命中范围、浅深/150%绘图及隐藏Shell键盘回归；其外围壳保留前轮组合结构和历史版本标签，不作为V1.0.2完整窗口或统计布局凭据。原先三个已删除快捷条也从组合示意去掉。当前原生统计和操作栏布局以新的隐藏组件图为准，真实产品仍待用户打开核对。
