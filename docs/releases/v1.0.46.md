**建议验收**：

1. 安装后进入 Hub 左侧「共用能力」，在「聊天接入」上方打开 **XshellB-MCP**。只勾选要测试的本机客户端，点「配置客户端」。打开 Xshell 8 已登录的标签页，回 Hub 选对应窗口，点「启动脚本」并在 Xshell 确认；从客户端检查当前目录。详见[接入与移除](../customizations/xshellb-mcp.md)。
2. 从升级后的 Hub 重新打开远程会话网页，在输入框留下未发送的草稿。切去其他浏览器标签页一段时间再回来，检查原会话、草稿和历史；如果目标端有新内容，应能接着显示，无需手动刷新。
3. 打开有文件修改记录的 Codex 会话，或在执行中切到后台再回来，检查文件变更和后续消息能否显示，且不会多发消息。实现与边界见[远程网页](../customizations/remote-web.md)。
