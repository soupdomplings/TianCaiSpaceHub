## 本批行为与兼容

「显示内容」新增第四项「产物」，默认关闭。开启后，随后生成的产物可随回复显示。关闭期间收到的产物进入手动清单，同一文件的完成通知或后台快照沿用首次的显示决定；仅从后台快照发现、未观察到生成时刻的文件也进入清单。切换保留此前已显示消息和上翻历史，用户上传的附件照常显示。右上「查看产物」可预览或下载已读取记录中的产物。普通文字保留，按目标端登记的文件标识与类别识别产物。

原三个实时开关及浏览器偏好继续沿用，升级后不会重置原选择。网页和小程序均包含四项显示选项。网页最终入口为 `index-BAfzyotQ.js`、`index-Bwc89lfs.css`；两端更新后，请从访问端 Hub 重新打开网页。

桌面远程连接增加「配对手机」「查看手机申请」「撤销手机授权」等入口。手机扫码后仍需电脑确认；会话、审批、追问及已登记文件使用原接口和权限。手机桥的新增加密依赖为已锁定的 `aes-gcm` `0.10.3`。设备令牌、配对密钥与请求记录进入系统保护存储。服务地址读取 `TIANCAI_MOBILE_RELAY_URL`，默认未配置时不连接公网服务。

本批固定输入包括 `src/remote_network/mobile/`、GUI 及会话文件桥，以及 `miniapp/`、`mobile-relay/`、`integrations/tiancai-squad-mini/` 配套源。MSI 安装桌面程序与既有配套文件；小程序工程、中转服务和站点补丁分别按开发说明使用和部署。

## 建议验收、回滚与交接

1. 两端升级并从 Hub 重新打开网页，核对第四项「产物」默认关闭。回复中生成的新文件应进入「查看产物」，用户上传附件和普通文字照常显示。
2. 同一条回复中打开或关闭「产物」，核对后续文件卡与图片的显示，已显示内容和上翻位置保留；重复通知/后台快照不应把隐藏文件重新插入对话。手动清单仍可预览或下载已读取的文件。
3. 无 AppID 时先导入本地演示工程；部署并配置合法服务后，再验证桌面生成配对码、扫码、电脑确认、手机续聊/追问/文件分片和撤销授权。真实账户与充值按服务和站点专题单独验收。

关闭「产物」可停止随回复显示后续新产物；需要停用手机连接时撤销授权或停用远程连接。实现回滚按各专题恢复相应源码并重新构建，保留原生会话、已支付订单及到账记录。历史 V1.0.54 包不具备本批手机接线和第四项开关，原包身份不改写。
