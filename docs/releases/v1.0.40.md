# V1.0.40 · 已有部分 Codex 项目时补齐侧栏

V1.0.39 在侧栏已经有一张卡片时漏掉了其余缺失项目。V1.0.40 逐个核对项目目录，保留已建卡片，区分可补建的卡片、可归类的会话和明确为「无项目」的会话。操作、匹配和撤销见[专题](../customizations/codex-partial-project-recovery.md)。

## Windows 验收

在现有状态上直接测试，无须删除配置或重建项目。完全退出 ChatGPT / Codex，在 Hub「接入设置 → 检查与修复」选择「删除配置后，项目或分组会话不见了」，先检查再修复。重新启动客户端，检查原来的卡片仍在、缺失项目出现、项目内能打开原来的对话。需要归类本人未记录账号的旧对话时再勾选相应选项并重新检查。真实安装与桌面显示由用户验收；macOS 本批不构建。正式发布、Actions 和标签不在本次范围。
