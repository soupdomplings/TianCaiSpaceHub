# V1.0.26 统一测试交付

日期：2026-11-11（北京时间）。基线为唯一 `main` / `149ee27`。本批集成后仅交付一份 Windows MSI；V25 原包及其验证记录保留原身份。源码已实现，Windows GUI 测试目标编译、57 项不同 Rust 定向用例及 12 项 Node 检查通过；release 构建和唯一包身份在本页单独登记。实机待用户安装验收，不触发 Actions、标签或 Release。

## 本批范围

- 天才搭档接入用户审核的干练搭档、软萌猫娘、温柔女友三套性格及少量自然 emoji；增加“完全访问”开关，默认关闭，开启后按用户指令删除配置不逐次确认。
- 对话支持 Hub 内最大化／还原：靠右、宽为 Hub 客户端一半、高为可用内容区全高；保留当前会话与草稿。处理末字折行，增加点阵圆环和等待省略号。
- 必要追问使用对话内选择／填写卡片，提交继续当前任务；支持已有客户端模型和专用渠道的原生删除；页面导航等待真实界面回执。
- 天工内置模型分享平时隐藏，只有用户明确说“打开天工内置模型分享”后才显示专用面板，不自动接入、登录或移除原分享。
- 修操作提示空正文，统一倒计时进度条和自动消失；小分队去掉“可用渠道”页签、修使用记录首次布局，并迁移菜单读取的等待弹层。
- 模块菜单、页签和公共弹窗增加短过渡；真实数据加载采用页内动态提示，保留已有内容并减少短请求闪烁，提示浮窗补弹出／收回动效，沿用“减少动画”设置。
- ZCode 启动识别补充官方登录服务仍在加载的首屏，明确本机数据/启动恢复的等待提示；保留本 Hub 已建立的启动连接供准备失败后重试，不重载已有工作区或含输入/登录中的页面。
- WorkBuddy 登录自带模型分享仅完成[静态评估](../customizations/workbuddy-builtin-sharing-assessment.md)，本轮未实现分享。

## 分工与当前状态

管理会话负责 ZCode、追问卡片、共享索引与版本、集成、必要离线验证及唯一打包。搭档代理负责性格、权限设置、分享入口、对话显示与测宽；工具审阅代理负责原生删除、导航回执及追问后端审阅，随后承担[加载动态](../development/loading-feedback.md)公共组件。界面代理负责操作反馈、小分队首屏、异步菜单和模块／页签／公共弹窗转场。付款、财务文件串行交给搭档代理收尾；主入口、客户端和请求记录的最终动态接线串行交回管理，避免共享文件并写。

相关开发代理均已交接并停止写入，最后由管理会话修正公共接线与版本材料。没有运行实际 Hub、客户端、Server、安装器或真实账户/模型调用，只进行源码、官方程序静态资料及合成夹具核对。
