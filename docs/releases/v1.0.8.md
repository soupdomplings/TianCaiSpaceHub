# V1.0.8 账户切页提速与密钥导入修复

2026-11-09，本地测试开发。唯一main，HEAD `25d024b2baa6af25f66bd69d5b237e0caa35df80` 加全部v13/V1未提交开发；不覆盖V1.0.7等旧包，不提交、推送、Actions或发布。真实站点加载速度和导入未代用户测试。

## 本次改动

1. 原先每次切页重新建立网络客户端，并依次读取公开设置、账户与组织权限。现在按配置位置、代理及本机监听端口复用服务/HTTP连接池，成功GET按账号、登录代次、路径与完整筛选短时内存复用。账户/权限30秒、列表/统计15秒、模型广场60秒、公开设置5分钟；单项1 MiB、总4 MiB/32项。右上刷新绕过缓存，保存前后、登录、退出、明确401清理；失败不缓存，迟到旧结果不能回填，付款及查单始终实时。保留原会话/写锁和未知写入不重放。首次及新筛选仍取决于站点响应。
2. 从Hub账户界面移除站内工具、我的订单、我的订阅、兑换、组织架构、组织审计、组织账号、邀请返利。保留账户、API密钥、使用记录、组织与扣费、模型广场、充值/订阅六组；其中组织管理及用量仍逐项授权。充值/订阅购买、当前付款结果确认及原管理内部门/财务能力保留，不改变网站菜单或业务。
3. 对照用户提供的站点源码，原生密钥导入创建票据缺少必须的Origin，失败又被本机统一包装成409。现在仅对固定站点的创建票据请求发送固定同源Origin，复用连接完成单次兑换及模型目录读取，校验来源、所选密钥ID和账号代次。账户显示可读错误；原最终预览、默认禁用、渠道隔离及配置后改保护保持。
4. 缓存后的下载明确遇到401仍强制验证/刷新会话，避免已缓存资料妨碍登录恢复。无持久配置迁移，回退只丢弃内存结果并恢复旧请求/菜单行为，不删除会话或渠道。

关键实现及TTL表见 [账户](../customizations/tiancai-squad-account.md)、[网页导入](../hub-external-import.md)、[实施](../development/v1-implementation.md)。本轮不改站点导出源码、浏览器接续配套补丁或线上服务，浏览器授权仍受原站点能力限制。
