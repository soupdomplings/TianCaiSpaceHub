# V1.0.34 源码内置组网测试交付

维护日期：2026-11-17（Asia/Shanghai）。关联 TC-025。基线 `main / dc9f288`。用户要求组网直接开发进 Hub、基于现有代码维护以便后续二开，替代下载独立运行组件；本批由管理统一集成和本地 Windows 测试打包，不触发 Actions、标签或 Release。

## 范围与分工

EasyTier 固定 v2.6.4 的核心及配套构建源码进入 `vendor/easytier/`，固定 smoltcp 源码作为本地依赖；保留来源、原版权、许可和修改说明。Hub 使用进程内网络运行域管理生命周期，配置留在内存，直接读取真实节点和路由。保留 TCP／UDP 穿透、中继、AES-GCM、无 TUN 用户态转发、设备配对和仅会话端口可达的访问规则；不启动外部 `easytier-core`／`easytier-cli`，不开放组件管理 RPC。

远程连接默认关闭；用户启用后直接创建／加入网络，不下载、不安装、不弹准备确认。已有网络身份和配对记录继续读取。新界面移除组件准备／移除按钮，停用只结束网络和网页服务并保留设置；旧准备接口兼容为空操作，旧移除接口只能清理正确归属的历史外置副本，不能移除内置能力或系统程序。

管理负责 `remote_network/mod.rs`、Cargo／锁、构建流程、共享文档和唯一包；复用网络开发负责运行域／节点状态，依赖开发负责上游源码裁剪及本地构建，界面开发负责原生入口及总体专题。共同工作区分开文件责任，全部停止写入后统一必要验证，不按子任务产包。
