2026-11-09，本地测试开发。唯一 main，HEAD `25d024b2baa6af25f66bd69d5b237e0caa35df80` 加全部 v13/V1 未提交开发；不覆盖旧 V1.0.6 包，不提交、推送、Actions 或发布。用户本轮反馈仅证明原生内置登录可完成，不扩大为账户全部业务验收。

## 本次改动

1. MCP 不再从已配置/已使用的客户端配置创建运行节点，通用及 Dumpling 都需可观测的真实工具调用。结束停流、三秒保亮再两秒暗淡、稳定位置及离开重进清理保留；客户端直连外部 MCP 无法由 Hub 观测，不猜测。实际请求日志不变。
2. 浏览器登录先只读探测站点可选授权能力；404/405/410/501、HTML SPA 回退及不兼容版本正常视作未启用，网络/5xx 单独视作暂时不可用，均可继续内置登录。不会创建无效授权请求，不向界面展示原始 HTTP409/JSON。2026-11-09匿名检查线上能力接口返回404，不是账号密码错误；已有配套补丁仍未部署，本轮未改站点导出源码或线上服务。
3. 登录后的工作区重构为紧凑分组导航；账户有余额、今日扣费、今日请求、可用密钥及近七天站点扣费曲线。个人资料独立展示有意义的信息，去除内部字段/value 调试表；任务列表使用中文列，日期只出现在记录页，分页只在多页时出现。小窗口和浅深色共用生产组件。
4. 导航数据刷新不产生用户选择事件，异步回包携带实际页面ID，避免菜单/正文错位及重复读取；读取失败禁用写入并可刷新重试。原密钥/导入、组织/财务/安全操作、六项组织权限、会话代次及未知交易防重放保留。

无持久配置迁移；revision、文件锁、备份、原子替换、后改保护和渠道隔离不变。回退不删除会话、渠道或资源，旧包保持原名。现行操作及源码定位见 [账户](../customizations/tiancai-squad-account.md)、[运行维护](../gui-runtime-maintenance.zh-CN.md)、[主题](../gui-theme.zh-CN.md)。
