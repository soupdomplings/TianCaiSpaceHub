# V1.0.9 模型页修复、统一设置与账户界面

2026-11-09，本地测试开发。唯一main，HEAD `25d024b2baa6af25f66bd69d5b237e0caa35df80` 加全部v13/V1未提交开发；不覆盖V1.0.8等旧包，不提交、推送、Actions或发布。由用户安装与实机验收，不主动运行Hub、客户端、安装器或真实账户/模型/MCP/付款。

## 本次改动

1. 使用记录移除“扣费方式”，保留时间、模型、输入、输出、实际扣费五列；Hub原始请求日志不变。除模型广场外按站点显式 `subscription_usd_to_cny_rate` 显示人民币，财务cents按元，账本仍USD，不把充值倍率当汇率。微额保留小数；无有效汇率显示¥—并说明原因，金额编辑暂不可用、原值保留。未修改金额保留原精度，编辑后还原原单位，模型广场继续原费率。
2. 充值/订阅页直接输入金额、选支付方式或在售方案并购买；移除重复弹窗入口。提交前实时重读付款配置，价格、规则、方案或支付方式变化时要求刷新核对。实际下单/查单不缓存，创建订单不自动重放，沿原订单继续付款。显示用汇率元数据仅按账号/代次缓存300秒，刷新/保存/换账号清理，读取失败不缓存。
3. 个人余额兜底在页内直接开关，保存后重读，失败不伪装成功；页内写操作携带账号ID和登录代次，写锁内再核对，旧API调用兼容。
4. 组织列表提供“管理组织”/“查看用量”入口，工作台按成员与部门、预算与授权、用量与报告、结算与财务分组，保留原18分区及权限、预算、批量、结算/预存/发票能力。详情按业务白名单分组，不枚举内部标识和凭据；扣费身份详情可直接使用。统一账户详情、表单、财务及进度窗口的主题、字号、留白和返回；固定取消/保存，溢出仅字段区滚动，部分既有原生选择器保留。
5. 个人资料移除“编辑资料”“安全设置”；退出登录仅在资料页正文下方显示，不在其他页面常驻。退出不删除已导入渠道。六组导航、八项入口精简、连接复用、密钥导入修复、七端配置与v13功能保留。
6. 修复原三端点击添加模型后编辑器可能保持零尺寸：直接布局嵌套模型页和编辑区，新增提供“返回已有模型”，返回保留草稿、放弃不写；没有读取revision时保留原编辑器。Codex也使用共用新增区，原渠道勾选与复制接口保留。单个实际位置自动选择，多Profile才显示位置选择；隐藏草稿空标题并收回留白，最小窗口默认表单和保存区完整显示。七端统一“接入设置”，提供本端/Profile配置位置、支持的程序定位和实际维护。WorkBuddy备份恢复移入此页，Codex初始化/执行/历史、天工同步/恢复、WebStorm两种组件操作保留，不新增虚假开关。详见 [客户端](../customizations/desktop-client-adapters.md)。

行为与口径见 [账户专题](../customizations/tiancai-squad-account.md)、[实施](../development/v1-implementation.md)、[指南](../v1-desktop-guide.zh-CN.md)。没有持久配置或数据库迁移；回退恢复旧界面和内存行为，不撤销已完成的站点交易。没有修改站点导出源码、浏览器接续补丁或线上服务。
