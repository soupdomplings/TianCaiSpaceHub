## 改动

- 复用现有 wxDragon 原生栈，统一内容边距、控件高度、间隔格、表面圆角、主题色和字阶。导航分区更清楚；选中、悬停和键盘焦点分别显示；保留窗口管理器标题栏和原生输入/菜单。
- 主次操作随页面任务调整。客户端运行状态突出启动，模型草稿突出保存；已明确指定为次级的按钮不会因中文标签误判为主要入口。
- 用量四项并入紧凑统计面；统一日志表面、客户端模型列表与编辑区、Skill/MCP 卡片和账户二级表单密度。统计、真实日志、业务请求、验证和配置写入语义不变。
- 不增加配置格式、API、模型映射、资源路径或账户站点依赖；既有 revision、锁、备份、原子替换及目标后改保护保持。
- 使用 `ui-ux-pro-max` 中匹配管理工具的 Minimalism & Swiss Style 原则及可读对比度/焦点检查。该库没有 wxWidgets 专属组件指导，本项目继续沿 wxWidgets 原生实现，未采纳营销页面或 Web/Mobile 组件模板。详见 [桌面视觉规范](../development/desktop-visual-system.md)。
