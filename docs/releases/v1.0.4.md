# V1.0.4 窗口自适应、导航和模型工作区本地测试交付

日期：2026-11-08。按V1.0.3用户九项反馈递增至 **1.0.4**，原v13/V1未提交开发和旧包保留。本轮实现与验证分别记录，真实Hub、客户端、Windows系统缩放与macOS待用户验收；未提交、推送、Actions或发布。

## 九项反馈与本轮行为

| 反馈 | 当前实现 |
| --- | --- |
| 默认窗口 | 取消启动最大化；普通1180×760 DIP窗口，仍约束实际屏幕工作区及最小尺寸 |
| 小窗口统计滚动/请求按钮 | 改真正Panel视口，无整页虚拟滚动；不足560 DIP高时默认趋势、可切分布，较高同屏。900×560 DIP最小外框下也覆盖启用筛选后的换行。去查看请求按钮，曲线/分布下钻及原日志保持 |
| 侧栏滚动和收起文字 | 仅隐藏侧栏及轻模型列表的滚动指示，滚轮/键盘/焦点滚动保留；收起仅图标和悬浮提示 |
| 展开列表点击就跳 | 展开冻结三位及其余客户端，点击按显示快照定位；收起才应用期间访问记录，持久格式不变 |
| 巨大或空设置页签 | WrapSizer不伸展末项；WorkBuddy去只有恢复的空设置页，有备份时恢复在模型页。Codex/天工保留初始化/执行等接入设置，新四端保留有实际用途的客户端设置 |
| 新增/复用难区分、列表生硬 | 七端统一添加模型按钮，同窗选择渠道或其他端来源；后者明确端名。轻列表普通行透明，无新增伪条目，无边框ListBox |
| 新四端表单缺失 | VS Code/Harness/ZCode/WebStorm有共用模型工作区，可编辑名称/上下文/输出/图片/强度，Harness另选协议；原生WebStorm能力由IDE提供。独立连接及显式来源同步保持 |
| Skill/MCP重复读取/常驻撤销 | 进入自动discover，十秒内重复进入合并；单一刷新图标强制重读，失败才显示重试。低频受保护恢复放设置，不常驻资源工具栏 |
| 启动下的读取意义不明 | 顶部只留启动，进入及添加模型后自动调用原读取服务。读取不等于保存，不周期性覆盖原三端未保存参数 |

## 接口、兼容和恢复

主要代码为`src/gui/{shell,usage_view,overview,client_header,clients,model_list,model_fields,resources,preferences,workbuddy,gmclaw,codex_tab}.rs`、`src/gui.rs`、`src/desktop/models.rs`及vendor滚动指示接口。`ModelWorkspace`、`UsageView`和`ClientHeader`直接供隐藏原生检查复用。

`/api/desktop/models`仅优化来源展示名及已知客户端归属，不改变routeId。原`/models/copy`、`/models/use`、客户端保存服务及资源use/edit/restore保持。新四端编辑保存使用填入时的row/revision快照；后台刷新不自动覆盖草稿或借新revision绕过保护。发现更新可显式载入，放弃未保存草稿。真实配置仍由revision、锁、备份、原子替换、后改检测保护，普通/WB/天工/各端副本及条目隔离保持。

自动discover只读取原生内容并收录到Hub库，不向其他端使用资源，也不启动服务。原生WebStorm能力控制由IDE提供；其他端仅按真实协议/能力保存，不因表单出现字段而声明上游一定支持。对象很多的分布表和长模型表单仍可在自身区域滚动，不把长页全局禁滚动而裁掉操作。

没有新增持久字段或迁移。recent文件结构保持；回滚界面需连同Rust/vendor滚动补丁整体处理，不能仅替换FFI一侧。V1.0.3及更早包保留，降级规则见[指南](../v1-desktop-guide.zh-CN.md)。恢复入口仅改变位置和条件，不删除备份或允许覆盖用户后改。

唯一main HEAD `25d024b2baa6af25f66bd69d5b237e0caa35df80`加未提交开发。Cargo/lock 1.0.4、EXE数字版本1.0.4.0、MSI ProductVersion1.0.4，UpgradeCode保持`{42B4BF3C-E660-4C83-96AA-56A4426B96A2}`。未读取或修改`zhenduan/`、`docs/.obsidian/`，未启动实际Hub/客户端/IDE/安装器，无真实模型/MCP/站点/付款调用。
