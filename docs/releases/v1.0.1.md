# V1.0.1 原生界面视觉修复本地测试交付

日期：2026-11-08。用户打开V1.0.0后反馈视觉与确认原型差距过大，无法继续功能验收。本轮修复正式原生程序共用视觉，版本递增为 **1.0.1**，保留V1.0.0与v13的原包、实现及历史验证。本页为本地测试交付记录，未正式发布。

当前状态：**代码已实现，Windows release、1154项离线回归、独立离屏/原生合成检查及新MSI静态核验通过；用户已打开本包并明确否决视觉，功能验收仍受阻。** 粗长滚动条、硬边控件和筛选区、过大指标及重复快捷条等继续由[V1.0.2](v1.0.2.md)修复。以下保留本轮当时验证与包身份，没有提交、推送、触发Actions或发布。

## 视觉修复范围

- 修复字体回退：Windows采用Microsoft YaHei UI，macOS指定PingFang SC，Swiss回退；原生控件用point字体，自绘用DIP比例换算，标题和统计数字建立层次。
- 222 DIP侧栏采用青绿主色、T品牌及导航图标，选中项浅青底；最近三个客户端保持稳定，第三端下展开、标题侧收起；设置/帮助固定底部，长列表在中间滚动。
- 初始窗口按原生DIP比例换算后约束到屏幕实际工作区，最小尺寸同样缩放且不强迫超屏；客户端状态页可在短屏滚动。新增两项尺寸回归覆盖150%宽屏与125%/150%/200%短屏。
- 页签改下划线，共用原生命令按钮呈现主/次/轻操作、hover/焦点/禁用/成功选中状态；带图标按钮预留文字空间，客户端选择保留成功才点亮、使用端排前。
- 运行图按内容限宽/限高、多路由滚动，客户端→Hub→模型→渠道，模型/渠道同排；多个请求按route/model合并，点击仍进入精确请求集合/渠道。客户端状态改双排连接图，替代放射星形。输入/输出曲线统一配色，日志与统计口径未改。

本轮继续Rust + vendor wxDragon/wxWidgets。新增共用Canvas、代码图标和抗锯齿绘制，以及独立ActionButton原生输入支持；旧业务复杂编辑器仍使用原生表单，不能声称所有对话框已与HTML逐像素一致。关键代码、vendor生命周期、配置与回滚见 [主题维护](../gui-theme.zh-CN.md)、[实施记录](../development/v1-implementation.md)。

& ./target/x86_64-pc-windows-msvc/release/examples/desktop_visual_review.exe target/v1.0.1-visual-review
