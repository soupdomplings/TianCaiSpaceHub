## 优先验收

1. **已经出现问题**：直接覆盖安装 V37，不必再删文件。打开 Hub 的「ChatGPT / Codex → 接入设置 → 检查与修复」，选择「删除配置后，项目或分组会话不见了」。记录当前项目数及归入项目的会话数；若检查提示有原库，完全退出 Codex，点修复，重新打开。
2. **核对实际侧栏**：在原账户里选「整理侧边栏 → 分项目显示」。分别打开两个原项目下的旧对话，核对名字、归属和原消息；独立会话不会被挪入项目。如报告有使用其他模型提供方的会话，可回到 Hub 的「Codex 会话管理」检查。
3. **需要额外验证自动恢复时**：从已能看到原分组的状态开始，先退出 Codex，把原 `config.toml` 改名留存（不动 `.bak`、数据库或全局状态），再从 Hub 初始化。确认回到同一项目和同一会话。曾自定义历史库目录时，如 Hub 在删除前保存过该位置或已有相应 `.bak`，新配置应继续使用原库；没有证据时不能自动找回。

未复测 V36 的用户可在同一 MSI 中接着验证[模型、渠道和生图清单](v1.0.36.md)。工作原理与回滚见[历史恢复专题](../customizations/codex-history-recovery.md)。
