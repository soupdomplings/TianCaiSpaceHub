# TianCaiSpaceHub 1.0 系列更新

覆盖版本：v1.0.0—v1.0.31。

1.0 系列带来全新的桌面界面、能帮你完成配置的「天才搭档」，以及更方便的多客户端模型管理。从接入模型、分配到客户端，到查看用量和管理会话，都可以在 Hub 中完成。

## 全新桌面界面

- 重构侧栏导航、概览和客户端工作区，统一浅色／深色主题、字体、表单和弹窗样式。
- ChatGPT / Codex、WorkBuddy、天工 Work、DeepSeek Harness、ZCode 五个客户端默认全部展示，常用操作更容易找到。
- 增加模块、页签、弹窗、数据加载和助手展开收起的动画，减少切换时的闪烁与生硬感。
- 成功和错误统一通过右上角浮动提示显示，带有说明文字和倒计时；精简页面底部的重复信息。
- 隐藏通用 Skill／MCP 管理以及 WebStorm、VS Code 的界面入口；Dumpling-MCP 改为独立入口，已有配置保留。

## 新增「天才搭档」

- 在 Hub 右下角直接对话，支持流式回复、Markdown、表格、复制、停止、清空和收起续聊；可展开为半个 Hub 宽度的对话窗口。
- 可以帮你读取配置、添加或修改渠道与模型、配置到指定客户端、删除配置、查看用量，以及打开相关功能页面。
- 支持读取已登录小分队账户的 API 密钥列表，选择已有密钥或按要求创建新密钥，再接入渠道并保存到指定客户端。
- 遇到多个候选模型或缺少必要信息时，通过选择／填写卡片追问；配置完成后回读实际结果，减少反复沟通。
- 提供「干练搭档」「软萌猫娘」「温柔女友」三套对话性格，横向点击选择，支持自然使用 emoji。
- 新增「完全访问」开关；开启后，已接入的配置和删除操作可以在用户交办范围内直接执行，减少重复确认。
- 提供常用客户端的官方下载地址和安装指引，以及 Hub 使用帮助。

搭档使用天才小分队配置的模型服务，对话费用由管理员承担；其他 API 调用及内置模型分享仍沿各自账户的计费规则。对话仅保留在本次 Hub 运行期间，已保存的配置不受清空对话影响。

## 模型与渠道管理升级

- 统一管理模型来源，同一模型可配置到多个客户端；常规模型支持为不同客户端分别调整参数。
- 按客户端实际能力展示上下文窗口、输出上限、思考强度和流式等设置，新建与编辑模型使用统一工作区。
- 新增 MiniMax 厂商模板，完善普通 API 与订阅套餐的密钥及接入说明。
- 优化模型获取、保存后的列表刷新和专用客户端模型名称显示，修复部分配置已保存但客户端未显示的问题。
- 重构「导入 Hub」界面，支持搜索、多选模型，并一次选择多个客户端接入，集中查看导入结果。

## 天工与 WorkBuddy 内置模型分享

- 支持将天工 Work、WorkBuddy 的可用内置模型接入其他客户端。
- WorkBuddy 首次登录授权并显示「独立分享已就绪」后，可以完全退出 WorkBuddy，由 Hub 继续调用和续期。
- WorkBuddy 模型目录按聊天用途筛选、按模型 ID 去重，同名但不同 ID 的模型分别标识，并展示来源提供的积分倍率。
- WorkBuddy 接入设置增加授权账号、授权状态、剩余积分和刷新入口；取消勾选分享入口仅隐藏相关按钮，已有分享继续可用。

内置模型分享默认隐藏。选择「软萌猫娘」后，在对话中提出「打开 WorkBuddy 内置模型分享」或「打开天工 Work 内置模型分享」即可进入；启停和分享操作也按该性格设置处理。切换性格不会自动停止已有分享。

## 增强启动与会话管理

- 天工 Work 支持使用已配置的外部模型增强启动，未登录官方账号时也可直接进入本地工作区。
- ZCode 增加外部模型免登录增强启动，修复启动未就绪、事件积压等导致的 HTTP 409 问题。
- 修复 DeepSeek Harness 模型不可见、长期显示「待核对」及部分安装位置无法启动的问题。
- 更新 ChatGPT / Codex 增强启动对新版 Ultra、Fast 的适配，完善程序路径、插件、浏览器连接、MCP 运行路径和代理继承等问题的分类检查与修复。
- 天工新增 AI Gateway 本地账号类型，统一增强工作区中新建、运行、列表和恢复的会话归属。
- 天工接入设置新增「会话历史管理」，支持按归属查看、多选迁入 AI Gateway，以及恢复原归属，保留会话内容、模型和附件。

调整天工历史前，请完全退出天工（包括托盘），并在 IM 中发送 `/q` 退出当前会话。旧历史不会自动迁入；当前适配已核对的天工 1.0.4 本地结构，后续版本的账号隔离和自建智能体结构仍需继续适配。

## 天才小分队原生工作区

- 在 Hub 内查看账户余额、实际扣费、请求趋势、API 密钥和使用记录。
- API 密钥增加今日／近 30 天实际扣费及独立限额展示，并可直接导入 Hub。
- 统一登录后账户恢复、表格、日期筛选和业务弹窗，优化切页速度，减少只显示「正在加载」的短暂弹窗。
- 按账户权限提供成员、部门、额度、限额、组织用量、挂账、预存和发票等管理入口；成员查看与编辑在同一窗口完成。
- 优化页内充值与订阅购买、金额展示及组织扣费设置，精简多余菜单和重复确认。

## 运行概览与用量统计

- 运行图按真实请求展示「客户端 → Hub → 模型 → 渠道」，请求结束后停止流动，MCP 节点依据实际调用显示。
- 支持按日期、模型、渠道和来源筛选用量，并从图表或节点进入对应请求日志。
- 天工本机协助产生的请求统一标记为「协助处理 MCP」，在概览、日志和用量中显示实际来源。
- 搭档可直接查询当前账户扣费、Token 用量及本机请求情况。

## 共享 Server 与本机协助

- 天才搭档与天工本机协助共用「天才搭档 Server」，分别启停，无需重复准备运行包。
- 两项功能均未启用时不下载、不安装、不启动；启用后检查已有程序，缺少或不兼容时先提示，确认后再准备。
- 运行包长期保留，两项功能停用后可手动移除 Hub 自行安装的 Server。
- 真正退出 Hub 时结束相关后台并清理临时会话；最小化或关闭到托盘时保留当前任务，已保存配置和运行包保留。
- 天工本机协助在「接入设置」统一管理，支持思考强度与完全访问设置。

## 平台说明

本次以 Windows 为优先平台。WorkBuddy 内置模型分享、ZCode 免登录增强启动当前仅适配 Windows；macOS 共用功能和各项客户端集成的实际效果仍待分别验收，不代表与 Windows 全部功能一致。

WorkBuddy 分享目前未适配 Responses 专用压缩接口。支持自行生成摘要的客户端，可通过普通模型调用缩减上下文；依赖该专用接口的客户端（如走远端压缩流程的 ChatGPT / Codex），长会话触发压缩时会提示暂不支持，尚无自动摘要兜底。各客户端的自动触发和压缩后续聊效果仍需分别验证。
