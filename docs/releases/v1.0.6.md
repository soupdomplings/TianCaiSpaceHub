## 对应反馈及实际改动

1. Codex 可见模型先选普通渠道，再搜索/勾选该渠道模型，内置与旧自定义另组；切换不丢选择。普通可见 ID 列表和原路由规则不迁移，客户端专用来源不混入普通目录。
2. 七端添加模型改为页内未保存草稿，明确保存才写入；来源可显式选其他客户端，复制后仍是独立配置。旧三端参数管理沿原编辑器，不借同名模型跨端路由。列表复用原生控件，避免选择回调内销毁当前控件；移除原添加模型弹窗路径。用户报告的偶发闪退未在真实 Hub 中复现，不能将代码风险修复当作实机已验收。
3. 客户端模型页调整容器和表单最小尺寸，旧 WorkBuddy/天工列表与表单分离，必要滚动限制在配置区，保存按钮留在可视区。常用信息默认可见，额外模型参数按需展开。vendor 滚动布局重新按内容计算虚拟尺寸，避免继承旧的大尺寸产生多余滚动。
4. 使用统计默认近 7 天统一常量与选中样式，日期选中与键盘焦点区分；输入/输出/缓存口径和实际请求日志不改。设置主题、语言和网络短选项选择器收窄。
5. 8 MiB 原为 Hub 自设文件保护；通用配置单文件改 32 MiB，Skill 完整包改 64 MiB/2048 文件，说明文件仍 256 KiB，超限保留原文件并提供处理入口。
6. 新增真实 [Skill 广场](../customizations/skill-marketplace.md)，默认公共 GitHub Skill 仓库、搜索和切换仓库、固定提交完整下载、二级确认后使用客户端，复用原资源事务与恢复，不执行包内脚本。
7. Windows wxWebViewEdge 3.3.2 明确拒绝 AtDocumentEnd 注入，V1.0.5忽略返回导致登录会话无法回传；本版改 AtDocumentStart 并处理失败。登录确认后切原生账户工作区，后续用量加载失败留在原生页给重试，不再误当登录失败。

8. 运行图取消固定高度限制，自适应可用空间，Hub 下方增加 MCP 分支。客户端已使用的通用 MCP 静态显示，Hub 真实桥接工具调用才流动；结束停流，保留 3 秒再用 2 秒暗淡，节点保留至重新进入运行状态。模型短请求和 MCP 调用各自保留少量内存结束证据，不改变日志/用量、配置与转发行为。直连外部 MCP 的调用不猜测，详见 [运行图证据与生命周期](../gui-runtime-maintenance.zh-CN.md#v106-运行图与-mcp-分支)。

9. 追加顶部资料/余额入口、默认浏览器授权、原生账户及“回到主站”独立会话接续。短期S256证明和单次授权、不读取Cookie数据库；取消与账号代次保护迟到回包。现站需应用 [配套补丁](../../integrations/tiancai-squad-browser/README.md)，未上线时提供内置登录/浏览器原登录状态回退。Hub 不需部署网站。站点Go完整编译与线上授权待其构建环境完成。

配置 revision、文件锁、备份、原子替换、后改保护、渠道隔离、来源同步、原参数与日志保留。未改变站点权限规则，无本轮产品配置迁移。新增浏览器接续需站点配套接口，本轮仅交付补丁，未修改导出源码或部署线上。降级时旧版的读取上限较低，超过旧上限的资源应由新版管理与恢复。
