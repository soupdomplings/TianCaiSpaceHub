## 行为与入口

- 产品、CLI、EXE、App 和安装输出统一 `TianCaiSpaceHub`；Cargo package 为 `tiancaispacehub`，保留兼容配置目录、协议、环境变量和安装升级身份。状态概览随 Codex、WorkBuddy、天工接入页签变化，公共页保留最近视角，不改变 IM 执行端。
- `/tg` 首次启用或选择天工，`/gpt` 返回 ChatGPT（Codex）；`/q`、`/s` 沿用当前执行端原有语义，天工不伪造主动取消。新建/恢复沿用飞书表单或微信/企微原菜单，固定逐会话目录、精确模型和原记忆。`/wb` 明确提示暂不支持外部执行并保持当前端；WorkBuddy 多模型配置和桌面启动继续可用。
- 天工自动准备内置启动口令并识别同用户已运行的官方实例，启用后每 5 秒后台自动重连，天工重启不必重新 `/tg`。只显式连接/启动可按需打开桌面；后台不启动或重放任务。创建真实天工任务，保存外部正文，恢复全部原生场景历史，保留认领、运行/审批/未知保护；原生历史步数 `1..1000` 原样透传，Hub 新建默认 `30`、配置范围 `1..200`。
- 已打开桌面窗口局部消息同步限定官方天工 1.1.1 及已核验 renderer 资源、同用户本机通道和精确任务/会话身份；保留草稿、模型与当前选择，原生运行、审批或未保存状态延期，不整页重载、不切换会话、不重放模型/工具。桌面启动按钮下方与概览区分准备、最近更新和失败；不能以绿色授权证明窗口已更新。
- 飞书/企业微信使用批准全部、拒绝全部按钮；企微先完整投递参数，再发送按钮。微信回复 `/1` 批准、`/2` 拒绝，兼容旧确认命令。审批独立于 Codex，绑定发送者/平台/账号/聊天、会话、配置和运行身份，15 分钟有效；旧卡、切端、重启或身份变化不执行，未知执行不重放，不新增永久或单工具授权。
- Windows Hub 主/兼容监听与天工启动均禁止句柄继承，退出只关闭自有 Hub 后台，保留天工运行及任务，不终止其他端口持有者。项目候选包含天工手动创建且没有任务的项目，完整读取失败明确说明不完整；飞书每页 20 项，微信/企微共用 8 项文字分页，企微下拉遵守 10 项上限，保留自定义及草稿。
- 天工准备/处理时飞书显示临时生成卡，最终同卡更新答复并结束生成态；企微仅有效普通消息回调使用同一 stream 收尾。微信接口没有编辑/撤回等待卡能力，直接最终文字。审批、队列拒绝、错误、取消/超时均有终态，原控件关闭未确认时仅有限更新固定状态、不重发正文或任务；平台断开或回执丢失仍可能不能确认卡已更新。
