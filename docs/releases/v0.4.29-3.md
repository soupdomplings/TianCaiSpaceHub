# v0.4.29-3 Windows 本地修复版

日期：2026-09-30。修复兼容站点使用 HTTP 地址时无法导入的问题。本版本为本地交付，尚未创建 GitHub 标签或 Release；已发布的 `v0.4.29-2` 产物保留原样。

## 行为与源码

- 支持任意符合外部导入契约 v1 的 HTTP/HTTPS 站点，包括 localhost、回环地址、局域网 IP 和自定义域名；无需 `TIANCAISPACE_IMPORT_ALLOW_LOCALHOST`。
- 统一 CLI、IPC、兑换响应、模型发现和保存地址检查。保留已有来源确认、跨站模型查询确认、来源一致性和禁止重定向；HTTP 提示合并到现有确认。
- 导入仍在预览前获取模型，默认禁用保存，空模型补全后才能启用。
- 源码基于 `e25ecd9e0d1a89111980f20590ef2f6baefb50b0`（`v0.4.29-2`）加本次未提交修复；`build-manifest.json` 中的源码提交/树是基线，`trackedWorkingTreeChanges=true` 表示包含工作区变更，不能按基线提交单独复现本包。

## 使用与回滚

升级前退出正在运行的旧版 Hub，保证请求由新版本接收。便携版解压到新位置后，在“文件 → 注册网页导入…”关联到新程序，然后从站点重新生成导入链接。其他设备上的站点需使用 Hub 电脑可访问的局域网地址或域名，不能用指向 Hub 电脑自身的 localhost。

配置格式不变，既有 HTTPS 渠道无需迁移。回滚前退出程序并备份配置，恢复 `0.4.29-2` 程序及对应协议关联；旧版会恢复原 HTTP 导入限制。完整流程见 [网页导入](../hub-external-import.md)，记录见 [二开变更记录](../customizations/CHANGELOG.md)。
