## 用户验收与兼容边界

先在天工接入设置查看历史；调整归属前完全退出天工（包括托盘）并在 IM 发送 `/q` 释放选中当前会话。多选迁入后重新增强启动，验证 AI Gateway 列表与旧会话继续聊；退出后恢复原归属，再验证新增内容仍可恢复。旧历史不自动迁入，新建会话直接归 AI Gateway。官方登录资料不改写。

项目壳共享，增强模式整组删除项目会提示改为分别删除可见任务，保留其他归属的 `.tiangong` 内容。Windows 真实显示、续聊、官方账号切换、IM 协作与 macOS 待用户验收；未来未发布的账号隔离版及自建智能体存储仍需取得新版后适配。
