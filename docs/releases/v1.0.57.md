## 实际行为与兼容

正文中已关联到当前会话的文件链接可直接下载；文件卡和「查看产物」提供分开的预览与下载。网页使用当前目标设备、客户端和会话读取文件，取得文件响应后交给浏览器按原名保存，保留中文与空格。隐藏的产物仍可从手动清单下载。普通外部网站链接沿用原打开方式。

旧链接没有当前会话的可下载标识时保留原标签，并提示「当前会话未提供可下载链接」。目标文件已移除时显示服务端原因，意外收到网页内容时不会保存为预期文件。网页生产入口固定为 `index-CgDw1agw.js`、`index-C9xPLfgw.css`。

目标 Hub 从 Codex／ChatGPT 与天工的历史及实时完成答复中识别明确 Markdown 成品链接，优先匹配当前会话已登记文件；首次关联时使用匹配的原生会话工作目录。仅关联指定交付子目录的直接成品文件，支持工作目录相对路径和系统绝对路径。沙盒链接仅在本会话已有完全同名登记文件时关联。源码行号、代码示例与无法确认的路径保留原文，具体目录和类型见原生会话专题。

文件登记增加的来源位置和交付目录信息可选，保留原目录记录的兼容读取。网页流式下载和手机分片下载共用登记文件的打开校验，按已打开句柄核对实际位置。历史页仅登记文件信息。最终修正兼容原生工作目录路径含点开头目录的冷历史，继续按指定交付目录关联文件。回退时恢复目标端及匹配网页资源，原生会话仍保存原文；既有产物开关、批注/填答显示和请求归属沿用原规则。

原生变更入口：`src/remote_sessions/delivery_links.rs`、`files.rs`、`mod.rs`、`codex.rs`、`tiangong.rs` 和 `src/remote_network/mobile/download.rs`。本批的文件关联为会话交付文件登记，打包根据实际实现核对，不假定新的系统默认应用或扩展名注册。
