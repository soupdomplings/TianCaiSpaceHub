# V1.0.47 · Xshell 8 启动脚本

**Windows x64 本地测试包**：`target/TianCaiSpaceHub-v1.0.47-test-20261119-172859-windows-x64.msi`，29,298,688 字节，SHA-256 `1e45d53abd183e67ba0fd70875142e8f4ccc5aad4e1b8a45ea5f13b0a32d4852`。构建自 `68c2103` 加本批工作区改动。已核对 MSI 1.0.47、EXE 1.0.47.0、升级规则和 5 个载荷；从 MSI 解出的程序确认内含 XshellB 三个 MCP 工具标识、完整接入脚本和现用远程网页资源。交付记录位于 `target/v1.0.47-xshell-launch-20261119/`。

用户在同一 Xshell 8 窗口手动点「工具 → 脚本 → 运行」能打开选择器，V1.0.46 的 Hub 却提示无法识别工具菜单。本机 Xshell 8.0.0120 的功能区没有传统菜单句柄。V1.0.47 可以从所选窗口对应安装版本的菜单资源识别入口，沿用原来的接入脚本和客户端配置。

**实机验收**：安装本地 Windows 测试版后，关闭之前手动打开的文件选择框，让 Xshell 停在已登录的目标标签页。回到 Hub 的「共用能力 → XshellB-MCP」，选中对应窗口并点「启动脚本」。预期 Xshell 弹出脚本的接入确认；核对后同意，回 Hub 点「刷新」，应显示已接入的标签页。之前已配置完成的 MCP 客户端不需要重新配置。如果自动启动仍失败，可点「复制脚本路径」，在 Xshell 手动打开的文件选择框内粘贴并打开。

本轮没有运行安装器、向真实 SSH 标签页执行命令或调用模型。用户实机验收待完成。XshellB-MCP 为 Windows 功能；未构建 macOS 包，未推送或触发发布。
