## 本批行为

会话右上角「显示内容」提供「思考过程」「工具执行」「文件变更」，首次默认全关。打开某项后显示之后到达的对应实时片段；关闭后停止追加该类片段，当前页面已经显示的内容保留。切换不补读历史、不移动上翻位置、不重建订阅。浏览器将三个偏好存入 `hub-remote-live-activity`，之后打开的会话沿用。

重新打开网页时，历史仍显示正文与附件；审批、追问、产物和正文继续按原路径处理。思考指运行端公开的摘要与进度。两端均需更新 Hub，并从访问端 Hub 重新打开网页；旧目标端显示升级提示。本次固定的生产入口引用 `index-BHR_Vi8B.js` 与 `index-CIKLRhYI.css`。

本批不包含 `miniapp/`、`mobile-relay/`、`integrations/tiancai-squad-mini/` 或冻结时尚未接线的 `src/remote_network/mobile/`。这些第二批文件保留，未加入第一批输入归档。第一批 release 已完成，EXE 和打包资源已固定，并已通知管理可开始第二批 Hub 接线；后续接线不影响本批固定载荷。

## 建议验收与回滚

1. 两端更新后，从访问端 Hub 重新打开网页。首次三项都关闭，历史只显示正文和附件，实时正文、审批和追问可继续使用。
2. 在正在回复的会话打开其中一项，确认此后出现对应片段，其他类仍隐藏；关闭后不再追加，当前已显示内容保留。上翻阅读时切换不应跳动或补出旧过程。
3. 新开另一条会话确认偏好沿用；重新打开已有会话，历史仍按正文和附件显示。产物可预览或下载，审批与追问只能按实际请求处理一次。

浏览器偏好不迁移原生会话或 Hub 配置。关闭三项即可停止显示新的过程片段；需要回退实现时，恢复此前网页源码/资源及实时订阅接线后重新构建。历史 v1.0.53 安装包及其原始身份保留，旧版不具备本次实时显示开关；回退不能视为新版功能验收。
