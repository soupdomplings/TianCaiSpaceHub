# V1.0.38 · 从 CC Switch 切回 Hub、模型选择与请求日志

本批在 [V1.0.37](v1.0.37.md) 的项目和历史恢复基础上更新。用户原来需要删除 Codex 配置、开关一次 ChatGPT 的操作，改为从 Hub 重新初始化一次。

## Windows 验收

1. **保留故障现场**：不用删任何文件。若 CC Switch 仍接管 Codex，先关闭其中的 Codex 接管，再完全退出 ChatGPT。到 Hub「ChatGPT / Codex → 接入设置」初始化／更新配置，然后到「模型」从渠道勾选两个容易辨认的模型并保存。从 Hub 增强启动 ChatGPT，在新对话的模型菜单中核对两项都在，同时打开一个旧项目里的会话确认归属仍在。
2. **旧清单兼容**：原来手填并已保存的模型仍可看到或移除；添加新模型只从渠道候选选择。清单没有变化时也可以再次点保存，观察运行端的实际刷新提示。
3. **WorkBuddy 请求日志**：在 WorkBuddy 里选已配置的 GPT 模型，发一条消息；回到 Hub 对照请求记录的模型和详情。如果渠道映射了另一个上游型号，两者不应混淆。

配置来源和回滚见[动态模型](../dynamic-codex-models.zh-CN.md)。不确定模型归属时不按近似名称猜测。
