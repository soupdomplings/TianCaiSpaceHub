**建议验收**

1. 两台电脑更新 Hub，重新从 Hub 打开远程网页。用 Codex／ChatGPT 的一条旧会话验证首次打开、上翻和实时回复均不再显示思考、工具和文件变更卡片；需要下载的文件仍在。页面只改变显示，不删除原会话。
2. 在同一条会话触发一次原生追问或审批，确认浏览器显示具体问题并能回答或拒绝。浏览器刷新后仍能处理未完成的请求，已经处理的不能再授权。仅在目标电脑本地弹出而没有原请求交给 Hub 的提示，应回目标客户端处理。
3. 在曾出现多个「脚本」菜单选项的 Xshell 标签页点一次「启动脚本」，等 Hub 显示「已接入所选标签页」。在「设置巡检权限 → 批量自动同意」输入 `pwd；df -h; free -m; uname -a` 后保存。重新打开设置应能看到这些条目。混入不支持的命令应看到对应条目报错且原设置不变。

真实 SSH、原生客户端和跨设备浏览器由用户验收；macOS 本批未构建。
