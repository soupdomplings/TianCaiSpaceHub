## 本轮行为

- **数字不换算。** 除模型广场原币种费率外，余额、扣费、额度与详情直接使用站点原数字，只将单位统一为人民币。例如返回 `12` 显示 `¥12.00`，不乘汇率或充值倍率；未修改字段保留原精度，微额仍保留小数。财务 `*_cents` 按原合同从分转元。显示不再等待付款配置或汇率；实际充值、订阅报价和付款前实时复核保持，站点账本不改。
- **添加模型就是列表内新建。** 当前已有模型列表末尾只增加一个“新建模型”草稿，直接配置，保存才生效；重复点击继续此草稿，切换已有条目再回来保留输入，放弃不写配置。WorkBuddy 使用原渠道、模型、协议和思考强度表单，天工使用原渠道、模型、输出上限、强度、温度策略和温度表单；不再先用简化选择页保存。Codex 同列表展示可见模型与新建项，原按渠道搜索勾选保留，新建仍沿独立别名复制；新四端保留完整能力参数。默认小窗口收紧参数布局，保存/放弃固定可见；真实超出才滚动。
- **复用仍是独立副本。** 旧两端完整表单可明确选择其他客户端来源，复制请求携带完整参数和原 revision，目标生成独立条目。普通保存、自动同步继续排除客户端专用来源；同名模型不会借用配置。来源 route / 模型 / Hub revision 与原生条目 revision 分别核对，文件锁、备份、原子替换和外部后改保护保留。
- **成员查看和设置在同一窗口。** 成员资料、余额、限额、菜单权限和扣费身份按权限直接编辑，各页保留草稿，保存后留在当前页；限额保留 `expected_updated_at`。批量动作与成员选择统一主题、搜索、选择当前结果和已选数量，返回不提交；实际批量余额/限额仍沿原确认与 API。
- **组织工作台精简。** 移除部门预算、设置预算、预算方式、预算提醒、可用分组、分组授权和用量报告；不删除主站功能、数据或兼容 API。其余内容分为成员与部门、成员额度、组织用量、挂账与余额，共 12 个分区。
- **额度和挂账使用实际字段。** 额度分配分别展示配置比例、预计分配、本期已分配、已用和剩余，比例最多两位小数、合计不超过 100%，支持锁定部分比例后均分和显式应用本期。未配置组织额度时提示去主站。财务分别展示全部挂账、已出账待清、未出账累计、已清金额，以及独立的预存/可用/预留；缺字段显示 `—`。原账单、清账、预存及发票操作保持。

## 配置、兼容与回退

无新增持久配置格式。新增草稿及成员分页面输入仅存内存，关闭程序不自动保存；后台状态更新不替换草稿创建时 revision，显式载入更新才读取新基线。修复放弃后旧快照回填和显式重新读取被旧输入覆盖的问题。

旧两端自动重读（包括重新进入页面）保留草稿的来源快照和 revision；读取或保存失败时才出现“载入更新”恢复按钮，明确操作后更新基线并保留参数。普通界面不常驻重复读取操作。

`GET /api/desktop/models` 新增只读 `codexVisibleModels`；原可见模型 ID 格式不变。`POST /api/desktop/models/copy` 可选 `workbuddy` / `tiangong` 完整原生请求，旧调用缺少这些字段仍沿原默认复制行为。原始来源和其他客户端条目保持不变。

回退使用旧包只能恢复旧界面和显示行为，不撤销已完成的站点操作。回退至 V1.0.9 会恢复其当时的展示换算。原配置操作的恢复和外部后改保护继续有效；不整份还原当前脏工作区，也不自动改用户运行配置。

关键代码：`src/gui/clients.rs`、`model_fields.rs`、`workbuddy.rs`、`gmclaw.rs`、`codex_models.rs`、`src/web/desktop_models.rs`、`src/desktop/squad_money.rs`、`src/gui/squad/organization.rs`、`src/gui/squad_form.rs`、`src/gui/squad_view/{member,allocation,selection,organization_data}.rs`。现行使用与接口见 [客户端](../customizations/desktop-client-adapters.md)、[账户](../customizations/tiancai-squad-account.md)、[主题](../gui-theme.zh-CN.md)、[实施](../development/v1-implementation.md) 和 [变更](../customizations/CHANGELOG.md)。

安装本轮新包并核对 1.0.10 后，重点检查：

1. 各端已有列表点击添加，只有一个新建项；完整参数可修改，切换保留输入，保存生效，放弃不生效。WorkBuddy / 天工从其他客户端复用后参数、路由与源条目保持各自独立。
