# V1.0.25 本地测试交付

日期：2026-11-11（北京时间）。基线为唯一 `main` / `eaf1dd9`。集成 ZCode、搭档交互、列表刷新、统一操作反馈、导入文案和统计查询，只交一份 Windows 测试包。V24 产物保持原名和身份。本记录先登记已实现与离线结果，最终 Windows 构建、包身份及授权提交状态在出包后补齐。

## 范围与定位

- ZCode 首屏探针原来只从资源计时记录发现启动模块。本机官方 3.17.2 的 316 个模块预加载中，目标 `styles-*.js` 为最后一个；计时缓冲区满或条目缺失即可造成页面已显示而探针仍超时。优先读取当前页面已解析的预加载/脚本地址，计时作为回退，继续原安装目录及页面状态校验。见 [客户端专题](../customizations/desktop-client-adapters.md)。
- 搭档处理回复裁切、Ctrl+Enter 已发送仍残留、消息/编辑输入的可见滚动条；保留滚轮和键盘操作。模型/渠道处理助手保存成功后列表未立即刷新、加载卡顿，以及专用客户端模型误显示渠道身份。最终实现入口见 [搭档](../customizations/genius-buddy.md) 与 [视觉](../development/desktop-visual-system.md)。
- 普通成功/失败使用右上小提示，绿勾/红叉、短说明和关闭；成功约 4 秒消退。取消关闭到托盘提醒，安装、删除等仍只确认一次。底部只保留执行进度、输入校验和真实业务状态，批量结果表保留。入口及范围见 [统一操作反馈](../development/operation-feedback.md)。
- 导入改成“保存到 Hub、要导入的模型、在哪些客户端使用”，按钮随选择说明实际动作。“更多设置”中的“保存后启用渠道”在选择客户端时自动勾选，取消客户端后恢复手动选择；旧别名是否替换用直白文字解释。完成/失败移到右上提示，不改变默认保存与逐项配置合同，见 [导入专题](../hub-external-import.md)。
- 搭档新增 `hub_query_usage`、`hub_query_requests`，复用当前小分队登录、实际扣费/Token 接口及本机请求库；缺少字段不补零，本机记录不冒充账单。默认简短自然回复，见 [统计查询](../customizations/assistant-usage.md)。
- [四套性格草案](../customizations/genius-buddy-personalities-draft.md) 按用户最新方向重写为干练搭档、软萌猫娘、温柔女友和严厉老师；第四套为面向成年用户的非色情角色。草案仍待审核，本批没有接入性格开关或生效设置。

## 分工与检查

管理会话负责 ZCode、统计工具与性格草案、版本及共享文档、集成、唯一打包及授权的 commit/push。UI 代理处理搭档渲染/输入，刷新代理处理列表/配置通知，反馈代理处理共用提示与导入文案；共享文件串行交接。三个代理均已完成并停止写入，最终只有管理会话收口导入选项和交付材料。

ZCode 增加三项 Node 回归，修复前两项失败（模块为 null），修复后共十项通过，覆盖计时缓冲区满、缓存/计时缺失、资源回退及原身份门控。另用本机官方 `index.html` 的 316 条真实预加载地址和受限计时记录复现：旧探针找不到、新探针找到；没有执行官方 JS 或启动客户端。

Windows GUI 测试目标编译通过后，31 个不同 Rust 定向用例通过：ZCode 4、用量工具 4、原助手配置工具 15、刷新合并 1、专用模型名称 1、提示摘要 1、成功清空及修订通知 1、RichEdit 实际高度 1、Markdown 解析 3。后两项原生控件检查只创建隐藏合成窗口并设置状态/测量，没有发送键鼠输入。检查脚本校对实际测试数，未将空筛选的退出 0 当通过。最后导入窗口的文案、提示及复选框显示收口另做 GUI 增量编译，未改上述用例对应实现。

报告集中于已忽略的 `target/v1.0.25-unified-20261111/`：`test-compile.json`、`affected-tests.json`、各定向日志、`zcode-native-page.json`；此前失败的类型/API 编译记录单列保留，已修正，不计为通过。固定产品路径清单和源码提交用于构建追溯，不做全树哈希。旧版未变范围沿原记录复用，不累计到本批执行数。

不启动实际 Hub、ZCode、WorkBuddy、Server、安装器或真实模型，不修改个人配置。真实界面、免登录启动及 macOS 待用户验收。本批不触发 Actions、不创建标签或 Release。

## 兼容与回滚

无新增持久配置版本和站点专用接口。新增助手工具只复用既有账户认证与读取接口，模型来源和共享 Server 生命周期保持；GUI 刷新只增加内存状态并沿原 revision 保护未保存输入。按各专题回退源码即可，已保存渠道、客户端配置、用户原有文件及成果保留。
