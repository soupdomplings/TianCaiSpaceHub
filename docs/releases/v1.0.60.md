日期：2026-11-20（北京时间）。本批桌面设置页、Windows 当前用户开机启动及天才搭档使用帮助／DNS 提示已实现；10 项离线定向检查、Windows release 和唯一 MSI 静态核验通过，真实安装及使用待用户验收。源码基于唯一 `main/68c2103ab0dc2654c0d66a8a1f9babb579b7b9a1` 加既有及本批工作区修改，尚未提交、推送或正式发布。

## 本批实际行为

设置页分为「外观与语言」「启动与集成」「连接与网络」「客户端与扩展」四组。正文宽度达到 880 DIP 时双列，窄窗单列并滚动；缩放保留原控件、选择及勾选状态。主题与语言通过「保存外观设置」提交，下次打开 Hub 生效；减少动效立即生效，保存失败保留原状态。代理通过「保存网络设置」提交，本机连接模式切换后回读。详见[桌面设置维护](../development/desktop-visual-system.md)。

Windows「设置 → 启动与集成 → 开机启动 Hub」默认关闭，点击立即保存并回读当前用户状态。启动命令为带双引号的完整 EXE 路径加 `gui` 参数，支持中文及空格。旧路径会提示更新；Windows 已停用时提示前往系统启动设置。同名内容不符合 Hub 命令时不覆盖。正式卸载只清理当前卸载账户中准确指向被卸载 EXE 的启动项，升级跳过清理。配置文件无需迁移；取消勾选可撤销，其他 Windows 账户各自管理。详见[开机启动及卸载范围](../customizations/desktop-and-packaging.md#v1060-windows-开机启动)。

天才搭档新增远程连接／审批、会话文件下载、Windows 开机启动、模型网关故障和 Xshell 五个帮助专题。模型通过 `hub_help({topic})` 按需读取；桌面「使用帮助」直接使用同一份本机正文，模型或网络不可用时仍可查看。查询帮助不执行导航，真正打开页面后才回报成功。远程说明明确：A 查看 B 的会话，由 B 的「显示内容（本机发送）」控制后续实时发送的内容。

模型错误只有包含 DNS 或 Windows 11001 等主机名查找证据时才提示域名解析问题；一般 502 不直接归因为 DNS，保留安全的阶段及状态码，不回显原始 URL、凭据或上游私密正文。提示说明排查方向，不代表现场网络已恢复。详见[天才搭档帮助与错误反馈](../customizations/genius-buddy.md)。

保留 [V1.0.59](v1.0.59.md) 安装器修复：文件占用页默认「关闭应用程序并继续安装」，`MSIRMSHUTDOWN=1` 允许系统处理超时占用，`MSIDISABLERMRESTART=1` 禁止安装后自动重开。成功页点「完成」结束安装，主动点「打开 TianCaiSpaceHub」才启动新版。单凭旧文案不能确认现场发生过重启循环。

## 用户安装及验收步骤

1. 保存旧 Hub 中尚未保存的编辑，保持它运行，再安装本批 MSI。文件占用页选择默认的「关闭应用程序并继续安装」，确认安装可继续；成功后点「完成」，确认 Hub 没有自动重开，再手动打开确认版本为 `1.0.60`。另可验证成功页「打开 TianCaiSpaceHub」能启动新版。
2. 在「设置」调整窗口宽度，核对四组内容、换行及滚动。分别验证外观保存后重新打开生效、减少动效即时生效，以及代理／连接模式等原设置仍可保存。
3. 勾选「开机启动 Hub」，确认离开并回到设置后状态保留；按需注销再登录，确认自动打开桌面。取消后再登录应不启动。也可在 Windows 启动设置停用后回 Hub，核对系统停用提示。真实登录、升级沿用及正式卸载清理待用户验收。
4. 打开天才搭档「使用帮助」，检查五个主题；有可用模型时可询问远程显示、文件下载和网关错误。实际发生 DNS／11001 时核对提示，无 DNS 证据的 502 不应直接判为域名错误。真实模型回复及原现场网络问题待验收。

本批构建与静态表检查不替代 Windows 真实升级、登录和卸载验收。若仍关闭失败，请记录发生在关闭等待、安装完成后还是手动打开后，以便继续定位退出与启动环节。
