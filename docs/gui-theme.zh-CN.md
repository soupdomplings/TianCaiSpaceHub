# GUI 主题维护

## V1.0.16 顶部菜单与主题日历

移除主窗口旧菜单整行，主题/语言/网络等在设置，关于和诊断导出在帮助；窗口与托盘行为保持。主题日期按钮及日历浮层替代两个大对勾旧控件，账户与组织共用；浅深/DIP/键盘见 [视觉规范](development/desktop-visual-system.md)，密钥统计原数值人民币见 [账户](customizations/tiancai-squad-account.md)。

## V1.0.16 主窗口外框

Windows 主窗口将标题区、侧栏品牌和顶部状态/账户连为同一 44 DIP 顶栏，去掉独立系统标题文字与底部版本状态条；版本保留侧栏底部；程序、任务栏、托盘和品牌区沿用原海豚图标。窗口控制采用轻量线条图标及焦点/悬停反馈，关闭仍进入原托盘事件，最大化/还原和系统贴靠、拖动/缩放保持。macOS 保留原生标题栏及交通灯。实现、维护和回退见 [桌面视觉规范](development/desktop-visual-system.md)，本轮验证见 [V1.0.16](releases/v1.0.16.md)。

同版移除天才小分队模型广场；下方 V1.0.11–14 的相关视觉记录属于原版本，不是当前功能。可用渠道归入账户，其他模型配置、天工内置来源和 Skill 广场保留。

## V1.0.13 组件规范

常规页面采用 20 DIP 水平边距、16 DIP 内容面内距及 4/8/12/16/24 间距格；普通按钮约 34 DIP 高；按钮/表面圆角分别 7/12 DIP。页面标题 16 pt，保留平台中文字体。统一浅深表面、表格底色、文字层级和强调色，降低嵌套边框；次级操作不因“添加/保存”标签被自动染成主操作，选中和键盘焦点分别表达。统计、日志、模型和资源的具体实现及主题检查见 [桌面视觉规范](development/desktop-visual-system.md) 与 [V1.0.13](releases/v1.0.13.md)。原生输入、Choice 菜单事件、系统减少动画和需重启换肤的行为保持。

## V1.0.11 筛选、模型广场与模型操作

账户筛选统一名称、格式/搜索 hint、常用日期、校验与重置；错误原位置修正。广场使用自适应模型块，强化名称/价格/厂商/分组层次，提供本地交叉筛选，真实溢出才滚动。模型保存/移除固定下方，字段按端与路线显示。OS 已保存会话先展示恢复或可重试错误，确认后再进入账户/登录。兼容见 [账户](customizations/tiancai-squad-account.md)、[客户端](customizations/desktop-client-adapters.md)，证据及实机边界见 [V1.0.11](releases/v1.0.11.md)。

## V1.0.10 同列表模型草稿与组织编辑

模型页直接在已有列表末尾加入“新建模型”，切条目即可回原配置；不再需要新增区与原编辑区之间的返回按钮。WorkBuddy、天工直接复用原完整表单，天工参数两列排列、协议短文本展示，选择器按 DIP 留足高度，保存/放弃固定下方；最小外窗检查包含所有参数的虚拟高度，不能只检查保存按钮。通用草稿切换保留原始输入，载入更新明确丢弃旧值。Codex 已有可见模型与草稿同列，按渠道勾选仍用原组件。详见 [客户端](customizations/desktop-client-adapters.md)。

成员详情内嵌资料、余额、限额、权限和扣费身份编辑，不再额外跳成员设置。批量选择统一为紧凑可搜索列表、选中标记、已选数和固定返回/继续；分配编辑直接列成员比例及本期数据，支持锁定均分及预留比例。组织工作台四组为成员与部门、成员额度、组织用量、挂账与余额；额度/挂账/预存用短指标与业务列表，不枚举内部字段。金额仅统一人民币标识，数字原样。实际合成布局、原生编辑回归及包身份见 [V1.0.10](releases/v1.0.10.md)，真实账户和显示缩放待用户验收。

## V1.0.9 客户端布局、账户二级界面与页内购买（历史）

客户端模型页切换时从实际内页布局新增与原编辑区，原三端新增提供带←的返回已有模型，保留未保存草稿；Codex新增也走共用编辑器，原渠道勾选保留。草稿隐藏完整标题容器并回收留白，小窗口默认表单保存区完整显示；展开参数后的真实溢出可滚动。七端同名“接入设置”，使用一致的程序与配置结构，配置路径按需展开、单Profile不显示额外选择；维护按本端能力追加，WorkBuddy恢复移到此处。模型、Skill和MCP仍在各自页管理，避免重复入口。详见 [客户端](customizations/desktop-client-adapters.md)。

充值/订阅采用页内切换、紧凑金额和支付选择、人民币预览与直接提交；资料仅保留查看及页内退出。使用记录五列，列宽随视口分配。组织工作台按成员、预算、用量、结算四组分层，筛选只对相应任务显示，读取时不残留上一页对象。详情以已知业务字段分组，隐藏内部标识和任意键；统一中文字体、主题、标题、间距和返回，表单固定取消/保存，溢出时仅字段区滚动。保留部分原生选择器，不宣称所有窗口均重做。金额口径与兼容见 [账户专题](customizations/tiancai-squad-account.md)，实际检查见 [V1.0.9](releases/v1.0.9.md)。

## V1.0.8 账户导航精简

生产账户导航改六组：账户、API密钥、使用记录、组织与扣费、模型广场、充值/订阅。移除用户指定八项入口，原账户指标、曲线、资料、小窗口及浅深色组件沿用；分页合成检查改用真实仍可达的API密钥场景。缓存/导入行为见 [账户专题](customizations/tiancai-squad-account.md)，验证见 [V1.0.8](releases/v1.0.8.md)。

## V1.0.7 账户工作区

天才小分队使用两层紧凑分组导航，移除侧面长 ListBox 及任意字段/value 表。账户以四项轻量指标与带悬浮值的平滑扣费曲线呈现；个人资料为自适应信息区，业务表格有中文列、紧凑操作和随窗口分配的列宽。日期仅用于相应记录页，分页仅在有后页时出现；可用性和加载状态不混为成功。最小窗口、浅深色、精简账号、空数据及错误使用生产 `squad_view` 组件作隐藏检查，范围及结果见 [V1.0.7](releases/v1.0.7.md)。MCP 配置不再触发运行图节点。



运行图画布填满可用高度，MCP 位于模型链下方，节点采用稳定位置，结束保亮 3 秒后 2 秒缓动暗淡，不立刻删除。多节点真实溢出仍可滚动；开启减少动效则无流动动画。生产容器与 renderer 共用于隐藏布局核验，证据见[本轮交付](releases/v1.0.6.md)。
## V1.0.6 模型与紧凑布局

Codex 模型目录改渠道选择、搜索和独立滚动勾选区，附加手填 ID 按需展开。七端新增均为页内未保存草稿，选择来源/模型后保存；移除原添加弹窗。ModelList 更新现有控件及标签，避免选择事件内销毁当前控件。WorkBuddy/天工模型页外层改 Panel，列表不拉长配置，只有字段区必要时滚动，保存固定可见；新四端模型参数按需展开。模型最小尺寸不再把完整表单的 best size 传播给父页面。

WxdScrolledWindow 在 Layout 里按实际 sizer 最小内容及当前视口重新计算 virtual size，并防止 SetVirtualSize 递归；不再用上次虚拟尺寸单向撑大。滚轮、键盘、焦点及真实溢出保留。统计近7天默认统一，日期选中有明确边界，键盘焦点不冒充另一日期选中；设置主题/语言/网络短选项限制为170/170/156 DIP附近，长文本输入仍可扩展。真实小屏/DPI/macOS由用户验收，隐藏组件证据见 [V1.0.6](releases/v1.0.6.md)。


V1.0.6追加顶部紧凑账户入口，短用户名与余额单行显示，完整资料放tooltip及资料页；未登录主区为居中浏览器登录、核对码与内置回退，无官网业务页替代原生模块。登录等待/网络失败/深色及最小外窗使用同一生产组件作隐藏布局核对，详见[账户](customizations/tiancai-squad-account.md)。

## V1.0.5 二级页面与登录入口

Dumpling标题前提供34 DIP的←，返回实际来源；资源管理客户端、未读取项目页有各自←。主页面保持侧栏导航，已有可关闭弹窗不重复加入页面返回。Skill/MCP全局卡片以使用摘要和“管理客户端”替代直接切换图标；二级页紧凑网格只改草稿，底部确认后应用，操作期间禁用选择及返回。只读文件视图替代原“配置位置”单选框，网格不随大窗口纵向拉长。

读取问题按资源类型/客户端显示少量入口，详情列原因、处理建议和文件夹；不再跨所有资源页铺红字。天才小分队未登录直接使用内嵌官网登录容器，确认后切原生工作区；离开模块清理私有视图和消息通道。状态API无本地会话时不等待网络。安全边界、离线与隐藏检查范围及MSI身份见[V1.0.5交付](releases/v1.0.5.md)，真实加载/登录、DPI与macOS待用户验收。

维护：2026-11-08。V1.0.0、V1.0.1 均被用户否决视觉，功能验收仍受阻。V1.0.3按V1.0.2实机反馈修复透明品牌图标、端内资源卡片、输入文字高度、日志铺满及统计交互；原V1.0.2紧凑布局保留。Windows 字体为 Microsoft YaHei UI，macOS 为 PingFang SC，失败回退 Swiss；普通控件仍用 point size，自绘文字采用显式像素高度乘窗口 DIP 比例，避免重复缩放。

V1.0.4按后续九项反馈取消启动最大化，保留1180×760 DIP及工作区约束。展开客户端时冻结显示位置，收起时应用最近访问；收起仅图标。`ScrolledWindow::show_scroll_indicators(false)`仅作用于侧栏和轻模型导航，滚轮/键盘/焦点滚动仍可用，其余长页保持滚动指示。模型列表普通行透明，选中/悬浮才出现底色；没有“新增模型”伪列表项，统一用添加按钮。

浅色主题为 `#f4f6f8` 主背景、白色侧栏与青绿 `#087f83` 主色；深色同步使用蓝灰表面和青绿强调。主标题18pt、统计数字20pt、原生正文10pt/辅助9pt。侧栏202 DIP、品牌区50 DIP，仅保留小图标和“TianCai Hub”，去掉“天才空间”大标题与品牌副标题。图标导航、浅青选中、三个稳定客户端位置与下方展开保持，设置/帮助固定底部。顶栏38 DIP、内容外边距18 DIP；页签使用下划线。主要操作、次要操作和轻按钮统一 hover、焦点、禁用与选中态；客户端小块成功读回才点亮，使用端排序规则不变。

运行图最大宽1300 DIP，基础高430 DIP，节点增多时按行增长并在图内滚动；多个请求按完整 route/model 合为节点，模型与渠道同排，无打开端和在途请求才仅Hub；未知调用方的真实路由仍显示Hub→模型→渠道。下方重复左侧菜单的聊天/Skill/MCP三个长条删除。客户端概览上排“客户端 → Hub → 模型”，下排 Skill/MCP/聊天执行；模型/渠道点击仍指向原精确请求集合与配置。各端启动操作统一在右上，去手工读取，进入或添加模型后自动读取；Codex/WB/天工仍调用原启动和读取逻辑。页签WrapSizer禁末项伸展；WorkBuddy无空设置页，其他端按实际业务保留接入/客户端设置。

使用统计顶部为可换行的日期、客户端、模型/渠道筛选；模型/渠道从当前范围完整历史值中选择，应用后显示条件数量，可直接清除。“查看请求”已删除，曲线和分布行仍可下钻。四卡高76 DIP、总宽最多1000 DIP；趋势使用水平切线Bézier曲线，缺失报告断开，不插值成零。仅输入/输出两条曲线，悬浮显示实际时段/请求/输入/输出。统计外层改Panel，无整页滚动；视口低于560 DIP时用趋势/分布切换，足够高时同屏。曲线最低168 DIP，分布表随空间扩展，对象很多时只在表内滚动；统计口径和原日志保持。

下拉、输入、按钮在来源、客户端、资源、账户、设置及旧维护窗口复用共用控件。选择框闭合态与输入框改浅边圆角；下拉项仍为原生菜单，输入内部仍为真正 wxTextCtrl，保留中文输入、密码、多行、选择、只读和文本事件。列表去重边框和网格，不将原表单改成 Web。底层 ScrolledWindow 保留虚拟尺寸、滚轮、键盘、焦点滚动，以8 DIP轨道/4 DIP圆角滑块替换原生粗滚动条，只有溢出时显示；长说明在窗口变窄时重新换行。

V1.0.3的客户端图标直接使用透明SVG/品牌轮廓，不再显示通用字母占位，按颜色和尺寸缓存。旧三端复用原Hub资源，新端来源见[第三方说明](../THIRD_PARTY_NOTICES.md)。展开按钮为180×34 DIP的三点，收起带双折叠图标。Skill/MCP改为1–3列卡片，本端默认只看当前使用及异常配置，可添加另列兼容项；全局保留跨端小块。卡片成功后点亮，失败保持原状态。

长卡片标题使用原生省略号并保留完整名称tooltip；vendor Rust层补`StaticTextStyle::EllipsizeEnd`，值为wxWidgets 3.3.2 `wxST_ELLIPSIZE_END`的`0x0010`，不新增C++对象类型或FFI调用。它与卡片最小宽度一起保留，避免长标题撑宽整列。

输入框的旧30物理像素高度不再压缩内部wxTextCtrl；最低取原生best height加12 DIP且至少36 DIP，字体改变后重算，单行垂直居中，多行保持拉伸。厂商六字段真实布局抽为`provider_form.rs`，日志布局抽为`request_view.rs`供隐藏检查复用；普通日志列随当前宽度填充，技术列允许横向滚动。日志的技术列开关、附加条件和分页文字显式应用主题前景色，避免深色背景黑字。`resource_gallery.rs`同样为产品与检查共同入口。

新增减少动态效果偏好；Windows 在用户未覆盖时读取系统客户端动画偏好。仅新鲜请求驱动流动，等待/终止停止；页面离开或窗口隐藏暂停相应刷新。主题切换仍保存后按提示重启，不承诺运行中完整换肤。新页面与主要编辑/支付窗口使用屏幕约束和滚动，实际 DPI、短屏及 macOS 外观待用户验收。

V1.0.1初始窗口先读取原生DIP比例，再换算1180×760逻辑尺寸并约束到屏幕物理工作区；最小窗口同样缩放并不超过实际可用大小，避免150%下仍用1180物理像素造成拥挤。客户端概览改可滚动容器。对应纯尺寸回归覆盖有空间的150%和125%/150%/200%短屏，不等于实际多显示器切换验收。

新四端模型使用共用`model_fields.rs`/`model_list.rs`，有来源、名称、能力和参数保存，不再只给一个裸列表；窗口变窄可在表单内滚动。编辑草稿绑定填入时的revision，轮询只更新状态/列表，配置改变提供载入更新。旧三端仍调用原受保护表单及服务，Codex多行输入不再硬性要求760物理像素宽。

导航、各端入口与验收路线见 [V1指南](v1-desktop-guide.zh-CN.md)，实现与验证见 [实施](development/v1-implementation.md)、[本轮交付](releases/v1.0.4.md)。

### 共用绘制与 vendor 补丁

- [visual.rs](../src/gui/visual.rs) 提供 Canvas、代码图标、圆角/曲线、文字测量省略、路由/客户端图与用量曲线；[controls.rs](../src/gui/controls.rs) 提供按钮、导航、页签、客户端小块与统计表面。窗口与独立 PNG 使用同一绘制函数。
- 自绘图、曲线、统计表面和品牌面板在尺寸变化时显式刷新整个区域；不能只依赖wxMSW新增条带重绘或下一次后台数据更新，以免拉伸时保留旧边缘。
- vendor 新 `GraphicsDC` 借用窗口或内存 DC，C++ 用 wxGCDC 抗锯齿；必须先 drop GraphicsDC，再 drop/blit/read 基础 DC。新增 `Font::set_pixel_height` 和 `WxWidget::from_dip`，仅用于显式缩放尺寸。
- vendor 独立 `ActionButton` 类型用 wxControl 接收原生捕获/焦点、Space/Enter 和 wxEVT_BUTTON，Windows 提供辅助访问角色/名称/默认操作及默认按钮语义。它不是 wxButton，不能向旧 wxButton FFI 强转。`Choice` 用隐藏的真正 wxChoice 维护数据/选择事件，显示层由独立按钮承载；程序选择静默，用户键盘/菜单选择产生原事件。`TextCtrl` 外层圆角Panel与内层真正输入框分别管理布局/事件；销毁后句柄失效，不能当同一种原生类型强转。
- [shell.rs](../src/gui/shell.rs)、[overview.rs](../src/gui/overview.rs)、[clients.rs](../src/gui/clients.rs) 使用共用层；资源、MCP、账户和新建表单的主要动作同步使用新按钮。后端保存、路由、revision/锁/备份/原子替换/后改保护不变；本轮不迁移配置。

### 独立视觉检查

[desktop_visual_review.rs](../examples/desktop_visual_review.rs) 是独立 example，通过 vendor `render_offscreen` 初始化绘图资源，不调用 Hub 初始化、后台、账户、客户端或网络。合成数据生成浅深主题、1366/1920窗口、1024 DIP/150%绘制、空闲、多端多路由和共用控件 PNG；外围壳为组合示意，**不是实际 Hub 窗口截图，不能代替真实 GUI 验收**。

同一 example 可构造隐藏的真实 Shell 检查字体、三端折叠/展开、导航和布局；不显示窗口、不进入事件循环，只向其自己的隐藏控件发送合成键消息。此检查不等于运行产品或验证客户端生效。命令与准确结果见本轮交付。

V1.0.2 新增 [desktop_layout_review.rs](../examples/desktop_layout_review.rs)，直接使用正式 Shell、UsageView、ClientHeader、输入/选择控件和绘图代码，检查实际原生组件布局并捕获其隐藏控件树。统计覆盖1366×900、960×640、1920×1080及深色，七端核对启动在读取上方；另核对程序/键盘选择、禁用、文本事件、销毁、虚拟尺寸与滚轮。PNG使用合成数据，不调用实际Hub初始化；这比旧手工组合壳更接近产品布局，但仍不是用户实际运行Hub截图。本机原生DPI为100%，实际125/150/200%、拖动/触控、多显示器与macOS均待实机验收。

V1.0.3继续复用真正生产`ProviderFields`、`ResourceCard/Gallery`、`RequestView`，增加10/13/15/20pt字体度量、全局/本端/窄窗/深色卡片及重复刷新、日志列宽铺满、品牌图标与曲线悬浮检查。字段和卡片中只放合成名称、示例地址及合成密钥，不读取真实客户端配置。悬浮命中使用与绘图相同的整数逻辑尺寸及物理像素取整，并允许边界邻近1物理像素，避免125%首个点落在半像素而失效。

V1.0.4检查改为统计双向容纳视口、短窗趋势/分布切换、七端页签不拉伸及无可见读取，新增六张生产`ModelWorkspace`捕获和能力填入/读回检查。另按900×560 DIP外框构造最小窗口，覆盖有/无筛选及趋势/分布：Windows 100%下扣除装饰后为884×521，启用筛选时工具栏换行，已缩紧两处间距以保留图表及操作。展开连续选端时比较原生位置及实际导航目标，覆盖显示槽位冻结。准确图片、构建与结果以[V1.0.4交付](releases/v1.0.4.md)为准，不沿用旧版本“启动在读取上方”作为新界面合同。

共用表单另有浅/深两张隐藏原生控件画廊，用于核对圆角输入、密码、多行JSON和选择器；它们是控件画廊，不是MCP业务页面。深色检查发现原生表头没有继承列表颜色；HeaderAttr同步字体/文字后，Windows主题仍覆盖背景，因此MSW表头绘制通知按列表颜色绘制文字、背景和排序标记，原生控件仍保留列拖动、点击与辅助访问。读取表头时显式请求文字/格式，避免空表头。错误文字也设置换行上限。

### 兼容与回滚

主题偏好字段和减少动态效果偏好沿用，不改客户端/模型/Skill/MCP/账户配置。回滚界面需将 Rust 调用与对应 vendor 补丁作为整体处理，不能只回退 ActionButton、Choice、TextCtrl、GraphicsDC或滚动层的一侧；用户降级安装规则见 V1 使用指南。旧V1.0.0/V1.0.1包与前期产物保留。Windows隐藏捕获仅在显式调用时使用临时绘制目标，正常产品绘制仍走原生PaintDC；非Windows捕获返回空。本机未原生构建macOS，也未真实打开新Hub，字体度量、窗口和旧编辑器的实际外观仍由用户验收。

以下是原有主题维护规则，继续适用；版本日期保留其历史归属。

维护日期：2026-09-30。适用工作区：`0.4.29-2`。这是沿用的上游 UI 基础能力；天才空间桌面定制见 [品牌与桌面](customizations/desktop-and-packaging.md)。

当前已经具备系统、浅色和深色三种主题。旧设计稿中“没有暗色模式、还需创建主题模块”的描述已过时，由本文替代。

## 当前实现

- [theme.rs](../src/gui/theme.rs) 提供 `ThemeMode`、配色及字体/间距等公共设计值；新增页面应复用这些值。
- `AppConfig.theme` 保存 `system`、`light` 或 `dark`；`auto` 作为 system 的兼容输入。
- [gui.rs](../src/gui.rs) 在创建窗口前应用 wxWidgets appearance 并初始化主题；菜单切换保存偏好后提示重启。
- 原生控件外观与自绘颜色共同适配；新增窗口不能只改背景而遗漏文字、边框或禁用状态。

## 修改时的约束

`set_appearance` 必须在创建窗口前调用。保持主题和语言偏好独立，不把主题切换写成已经支持运行中即时切换。布局尺寸应允许中文和较长模型/服务地址显示，必要时使用滚动区域。
