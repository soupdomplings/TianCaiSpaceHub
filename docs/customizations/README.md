## 沿用的上游能力

本地二开继续依赖 AI Gateway、IM remote-control、多执行端路由、Codex 初始化与恢复、增强启动、插件兼容、各厂商适配器及请求日志。Kimi K3、ChatGPT 账号登录、Responses WebSocket 和新版内置 GPT 目录来自上游合并；二开记录描述其与定制功能的衔接，不能把上游整项功能记为本地新开发。
