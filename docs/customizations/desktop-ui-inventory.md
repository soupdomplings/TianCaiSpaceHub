## 原桌面与原型评审盘点（历史）

下表“现状”仅指 v13 工作区、没有启动旧 GUI；“建议去向”是当时规划。它用于防止重构遗漏，不能当成 V1 尚未实施或所有环境验收声明。

更新：2026-11-08（北京时间；原桌面核对 2026-11-07）；基于唯一 main `25d024b…` 加 v13 未提交工作区，版本 `0.4.30-13`。本表由现行源码/专题还原，未启动实际 GUI。**“现状”是代码确认，“建议去向”是待评审方案**。总体方向、状态/接口和回归见 [重构方案](desktop-ui-redesign.md)，[原型](../mockups/desktop-ui-review/index.html)仅覆盖关键场景，不代表所有表项已实现。

第 3 稿最新决定：全局运行图、客户端六节点概览和 Codex 接入设置均保留；模型/Skill/MCP 按选定客户端直接使用，必要决策才展开。通用管理和新客户端仍属规划，现状表不把原型当作已有功能。详见 [管理规格](desktop-capability-management.md) 与 [Magpie / 客户端适配研究](desktop-client-adapters.md)。

第 3 稿调整建议去向：全局导航改“概览 → 运行状态 / 使用统计”，原连接信息进入运行状态；“活动记录”改“请求记录”，增加统计下钻与全范围分页设计；模型与渠道增加“我的模型”及各端独立复用。下表现有能力不变，统计聚合、统一复用与通用管理仍不是产品已实现接口。

## 重复与断点汇总

| 类型 | 确认项 | 处理方向 |
| --- | --- | --- |
| 可以自动读而让用户手工接续 | WorkBuddy/天工来源刷新、完成来源后回客户端、保存后状态更新 | 进入/操作成功自动只读刷新，保留有草稿时的保护 |
| 相似按钮外观但语义不同 | 来源获取目录、同步已存渠道、保存 Codex 可见列表；客户端保存与启动 | UI 统一动词/层级，不把不同持久化边界合成一次隐式全量写 |
| 无需复制入口 | 大概览状态+当前客户端说明、四平台常驻新增、各页全套维护按钮 | 工作台摘要只导航，当前页主操作明确；平台/维护按对象组织 |
| 已经改善，必须继承 | MCP v12 单主操作、来源空表自动获取、v13 地址修正、既有表单滚动 | 不倒退增加手工检查，也不重新做一套行为 |
| 缺可操作上下文 | 无候选模型错误、来源改动后副本不同步、并发保存报错 | 保留入口/条目身份、草稿和最新快照，定向解决后继续 |
| 本质不能自动完成 | 客户端实际模型选择、真实授权挑战、危险修复、未知执行结果、原生工具信任 | 清楚说明下一步，提供返回上下文；不以“少点击”越过这些边界 |

## 覆盖与验证边界

盘点覆盖主窗/7 类页、上述代码可达窗口和菜单/托盘入口，以及 IM 内关键业务衔接。未执行运行时控件树遍历，不能断言所有平台特有原生提示均已视觉核验。新增账号模块另核对用户提供的站点 Vue/Go 源码；原型 117 组账号页面/子页标记生成及权限/导入等 18 组行为检查通过，不是完整站点表单或后台实现。产品原生布局/无障碍/长文本、真实平台登录与任务都待后续用户验收；设计原型仅用于评审推荐布局与关键状态。

后续实施时，按编号记录“旧入口 → 新目标 → 实现状态 → 离线验证 → 用户验收”覆盖表；移除旧入口前核对所有已实现操作仍可到达，尤其专用渠道高级管理、历史归属、修复记录、MCP 断开/环境删除、日志技术字段、网络和导入关联。新增功能另按维护规范登记，不能把本表中的建议写为当前行为。
