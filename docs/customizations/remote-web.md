## 入口与行为

在 Hub“远程连接”选择设备并打开网页。网页入口 `/remote/`，`device`、`client`、`session` 查询参数只携带对象标识，不带凭据。目标设备、原客户端、原会话始终分别选择；切换设备或客户端时清除旧会话定位，避免把另一运行端的会话 ID 带入请求。

Codex 和天工采用各自的会话视图：项目与会话侧栏、原会话标题与目录、流式正文、输入框和运行操作；天工使用绿色强调色、任务边栏及工作空间标题样式。没有复制原应用安装资源，布局以首版功能对应为准，不宣称逐像素相同。

项目和会话列表按页读取，可显式继续加载；项目分页按真实 ID 去重，侧栏筛选与新建表单共用已加载目录。列表刷新保留已加载后续页，搜索作用于已经加载的会话。历史小页按时间正序展示，可向前分页。正文支持 Markdown、表格、列表和代码。已完成消息通过 React memo 避免流式追加时反复解析整段历史。

页面直接读取原生历史和事件，不在浏览器持久保存聊天副本。未发送草稿和已上传附件选择只在当前网页内存中按设备、客户端、会话分开保留；主题选择是唯一 localStorage 内容。浏览器刷新后重新读取原生状态，未发送草稿不会恢复。

## 调用与权限

- API 与结构见 [远程会话协作契约](../development/remote-session-contract.md)。所有目标请求附 `X-Hub-Target`，认证信息由本地 Hub 代理持有。
- 事件使用 fetch SSE，支持拆分 UTF-8、CRLF、多行 data、游标去重和会话身份过滤。断线后读取最新原生快照再订阅，不自动重发消息或工具操作；已分页历史存在公共锚点时保留早期内容。
- 原生快照已有的 item 设为基线，其后无法确定是否已包含的 delta 不直接重复拼接，而是以 250 ms 合并读取原生绝对内容；新 item 继续流式追加。后台补读保留既有 SSE 连接与游标，并保护已完整观察的新项及读取期间收到的完成项，防止旧快照回退覆盖。原生 `item/started` 重播不清空基线正文，明确完成的 `item.updated` 才替换并解除基线；终态变化再补读一次。工具／思考增量沿事件可信 role/type 渲染。
- 关闭页面或切换会话仅取消订阅，不调用停止。停止由用户点击并走原生 stop，等待服务端实际状态；审批结束同样以服务端返回和快照为准。
- Codex 原生审批 choices 的 `option:n` 值原样回传；结构化追问支持单选、多选和自由填写，必填内容未完成时不允许提交。
- 各控件依运行端能力显示或禁用。天工续聊固定原任务模型；新建时选择真实模型和项目，没有项目时引导在目标端先建项目。Codex 用目录弹窗选择目标 Hub 已添加的文件夹或其 Codex 原生会话目录；可以搜索、分页、刷新，取消不会创建会话。跨设备时不会弹出访问电脑的目录选择器。
- V1.0.45 区分已确认的空会话和读取失败的会话。读取失败保留原始会话定位及错误提示，可以重新读取；页面不把失败当作新对话，也不重发消息。

## 附件与产物

在已有真实会话中选择或拖入附件，通过专用 files 接口逐个上传；每条消息最多选择 20 个。发送成功后清空编辑器和附件选择；失败保留输入并刷新原会话，不自动重试 POST。从输入区移除附件时调用 DELETE，后台仅允许删除未发送的上传文件。

文件读取始终使用当前会话 files/{id} 接口，不直接使用原生消息中的主机路径。图片、文本、代码、PDF 可以预览，其他格式提供下载；大文本只预览前 1 MB，完整内容通过下载查看。远程 Markdown 图片显示为可点击链接，不自动加载外部资源；原始 HTML 不执行。产物按文件 ID 汇总，并保留原会话关联。

## 交互与构建

Ctrl／Command+Enter 发送，普通 Enter 换行；中文输入法组合期间不会发送。用户上翻后停止自动跟随，提供“回到最新消息”；向前分页保持阅读位置。正文不裁切，消息输入框可滚动且隐藏其滚动条，长中文消息使用自然换行和 `text-wrap: pretty`。

支持浅色、深色和跟随系统，使用系统字体和本地 SVG 图标，无 CDN。模块交互和浮层采用短动画，`prefers-reduced-motion` 下关闭位移动画。成功／错误提示包含正文、关闭按钮和 6.5 秒倒计时，不在按钮下堆放结果日志；加载使用页内占位。

源文件位于 `web-remote/`，产物位于 `assets/remote-web/`。`npm ci` 按 lockfile 安装开发依赖，`npm run build` 完成 TypeScript 检查、Vite 构建及第三方声明生成。运行依赖和版权说明保留在 `THIRD_PARTY_NOTICES.txt`，随网页资源提供；用户使用时无需 Node.js。
