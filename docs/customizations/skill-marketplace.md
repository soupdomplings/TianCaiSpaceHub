# Skill 广场与共用仓库

维护：2026-11-08。适用 V1.0.6，关联 TC-017。原生管理与本机 API 已实现；Windows 构建、离线验证和包身份集中见 [交付记录](../releases/v1.0.6.md)，真实客户端由用户验收。

## 使用方式

进入「Skill 管理 → Skill 广场」，默认读取 [anthropics/skills](https://github.com/anthropics/skills) 公共仓库。名称和说明读取实际 `SKILL.md` 元数据；支持搜索。它是公开示例 Skill 仓库，不是 TianCai 新建或托管的服务；Hub 不需要另行部署。可通过「公共仓库」切换成自己的公开 GitHub Skill 仓库，地址格式为 `https://github.com/作者/仓库`，支持一个仓库内的多个 Skill 目录。

点「使用」进入二级客户端选择页，点图标只修改草稿；「应用更改」后才下载完整包并配置所选客户端，返回不写入。共享 Skill 目录仍同步选择并确认影响，独立目录保持独立。WebStorm AI Assistant 模式尚无原生 Skill 能力，保持禁用，Air/ACP 可用；只显示已发现的客户端位置。配置成功后在「我的 Skill」管理，保留原备份、冲突及后改保护。客户端是否需要新任务或重开，沿本端原有加载行为。

每次目录读取固定一个 Git 提交，下载沿该提交和完整 Skill 子目录，包含附件、脚本和资源；存在仓库根许可且包内无 LICENSE 时附带 `LICENSE.repository`。Hub 只下载和配置，不执行包内脚本、不自动安装其依赖。Skill 能否在所选端完成任务，仍取决于其指令、依赖和客户端能力；按仓库及包内许可使用。

## 读取、缓存和失败

- 公共目录缓存为现有桌面状态目录中的 `skill-market.json`，含仓库、提交、名称/说明及时间，无账户或凭据。再次打开先读本地缓存，刷新才取新版本；首次无缓存自动读取。刷新失败保留旧缓存和已有 Skill。
- 只支持匿名公开 GitHub 仓库，不填写令牌、不登录 GitHub，不运行 Git 或包管理器。GitHub 匿名限流、网络失败有刷新和切换仓库入口；不会伪造示例资源。其他代码托管平台、私有仓库和向远端发布暂未实现。
- 索引最多 8 MiB、30000 个树条目和 256 个 Skill；文件类型、路径、链接/子模块、单文件及完整包容量均核对。文件按固定提交下载，包中异常不会自动删减后继续使用。
- 通用配置单文件上限为 32 MiB，完整 Skill 最多 64 MiB/2048 个文件，`SKILL.md` 保持 256 KiB。原 8 MiB 是 Hub 自设内存/备份保护，不是客户端或模型接口上限；本版提高普通文件容量，继续限制无界读取。现有 ZIP 导入仍有其下载/存档独立上限，界面明确具体限制，不宣称无限导入。
- 先核对资源 revision 和客户端位置，下载后再走原 `Library::import_skill` 与逐端适配。源配置在此期间改变则停止；跨端不宣称原子事务。部分成功保留成功端，失败在资源管理核对；写入结果未确认不自动重放。

## 代码、接口和回退

领域 `src/desktop/skill_market.rs`；正式界面 `src/gui/skill_market.rs`，嵌入 `resources.rs` 的全局 Skill 页。`GET /api/desktop/skills/market` 读缓存；同路径 POST 指定公开 repository 刷新；`POST /api/desktop/skills/market/use` 使用 `commit/path/revision/targets`。所有修改接口沿本机可信请求校验；外部请求复用 Hub 代理配置。

资源仍复用原库和各端格式，无持久格式迁移。退出广场或切换仓库不撤销已经使用的资源；停用和受保护恢复仍在现有管理入口。回退旧版可忽略新增缓存，已配置客户端不因回退界面自动删除。旧版 8 MiB 读取上限可能不能管理新版允许的大文件，需保留新版恢复能力。

公共仓库只读核对记录在 `target/v1.0.6-models-skills-20261108/public-repository-review.json`；目录数量属于核对时点，不作为固定产品数量。离线回环仓库验证固定提交、真实元数据、完整相对附件和许可；不等于真实客户端已加载或调用成功。
