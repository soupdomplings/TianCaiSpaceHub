## V1.0.25 正文、草稿和配置刷新

用户反馈助手正文末行被裁切、Ctrl+Enter 已发送却留下输入文字，另要求隐藏消息区和编辑框的可见滚动条。正文旧高度以 wx 基础字体字高乘估算行数，不能代表 RichEdit 的中文回退字体、混合样式与实际软换行。Windows 现在在确定控件宽度后，使用 RichEdit 的同步 [EM_REQUESTRESIZE 尺寸通知](https://learn.microsoft.com/en-us/windows/win32/controls/em-requestresize) 读取实际内容高度，再向消息块、正文和气泡逐层传递；测量通知仅临时监听本控件，结束即恢复原事件掩码和监听。保留宽度/内容缓存，不增加每次轮询的全量排版。macOS 保留现有估算路径，需单独验收。

输入快捷键旧回调没有显式消费事件，而 wxDragon 默认 `Skip(true)`；原生多行框继续插入换行，导致异步成功响应中的原文比较失败。Ctrl+Enter 现在明确 `skip(false)`，只有成功且输入仍为原提交草稿时才清空；发送失败和提交后新写的草稿保留。Esc 和输入框末端的定向 Tab 同样消费已处理事件。对话 ScrolledWindow 隐藏滚动指示，输入框增加 `NoVScroll`，正文继续使用已有原生无竖栏样式；滚轮、键盘滚动及原生选择复制保留，不将输入框滚轮转给消息区。

助手状态新增读取现有 Hub 配置的 `configurationRevision`，首次有效及后续非空修订变化通知页面刷新，不等待整轮工具对话结束。缺字段不覆盖已观察修订；不解析回复正文、不新增哈希或独立版本层。`AssistantUi::on_configuration_changed` 由 GUI 接线到已有模型/渠道刷新流程，后台实际写入与客户端来源显示修正的集成状态由管理会话记录。常规配置、账号切换和工具权限语义不变。

准备/移除 Server 的确认接入统一主题确认框，仍只确认一次。清空临时内容、准备和移除完成后使用统一短提示，明确操作失败使用可展开的统一错误提示；轮询、消息流、业务详情及当前运行状态仍就地展示，不因每次刷新或发送重复弹提示。未增加下载、自动安装或新确认步骤。

## 当前行为

左侧独立“天才搭档”模块集中管理启用、运行端、登录、模型服务和临时清理，默认关闭。启用且共享“天才搭档 Server”已准备后显示右下角对话图标，Hub 内浮层支持发送、停止、收起和清空；小分队已登录且管理员模型配置有效后才创建后台、允许发送。缺少运行端时界面提供用户确认后的准备入口，复用 [本机协助](tiangong-local-assistance.md) 的同一共享运行包；不会自行安装系统 Codex、修改用户 PATH 或个人 Codex 配置。两功能均停用且后台退出后可由用户手动移除 Hub 自管运行包。

助手通过官方 Codex app-server stdio、`experimentalApi` 动态工具协议工作。一次 Hub 运行仅保留当前账户的一个 app-server thread，多轮消息继续该 thread；收起界面不停止任务、不丢失当前对话。停止发送 `turn/interrupt`，撤销待确认删除/凭据询问并关闭本轮上游流；已发生的配置修改保留。清空先关闭整棵后台进程树，再清临时目录、内存消息与临时凭据，下次发送才新建会话。没有闲置五分钟自动清理。

用户退出或切换小分队账户时中断旧会话、清空内存和临时凭据，界面未发送草稿随 `conversationId` 变化清除。工具分派、确认后写入及结果返回再次核对原账户代次和会话 epoch，防止旧对话继续修改。Hub 退出同样停止树并清理；启动时仅回收该功能的 UUID 临时会话目录。清理失败保留后台归属并显示原因，暂停新消息，用户可点击清空重试。Windows 使用 Job Object 随 Hub 句柄关闭结束树；macOS 使用独立进程组，异常遗留只在 PID、启动身份、运行端绝对路径、原 Hub 已退出同时匹配时结束原组。无法确认归属则保留并记录原因。

临时 `CODEX_HOME` 和 workdir 位于本机 feature 状态目录 `assistant/runs/<UUID>/home` 与 `work`，不读取个人聊天、历史、插件或项目配置，也不跨 Hub 重启恢复对话。永久共享运行包位于 `companion-server/`，与临时会话分别管理。

## 模型与费用

只使用小分队管理员配置的模型，接口见 [配置契约](../contracts/assistant-server.md)。登录后只从一个 GET 取得开关、名称、普通 API 地址/助手专用凭据、协议/流式偏好及模型参数，Hub 直接连接已有普通模型 API；不新增助手专用推理或压缩 POST。Hub 不使用用户普通渠道、不查看用户余额，也不把登录 JWT 或模型密钥给 app-server。运行端仅取得随机本机会话 token。

模型参数为 ID/显示名、上下文窗口、可用/默认推理强度和推理支持；不再要求远端工具、压缩或费用声明对象。协议支持 `responses` 和 `chat_completions`，使用 Hub 已有转换器把 Chat / 非流式结果适配给 Server。Chat SSE 按完整行解码，保留跨网络分片的中文和工具参数；取消、上游错误及缺少结束信号的提前断流结束请求，不补造完成事件。上下文写入 app-server 模型目录，压缩阈值为 80%，显式使用 Server 本机摘要（`remote_compaction="unsupported"`）；摘要继续请求同一普通 API，不依赖独立压缩接口。配置每 60 秒更新；临时读取失败保留已知配置与对话，成功确认管理员关闭或模型/连接变化时隔离旧会话。关闭功能不访问远端配置。

模型实际调用时，请求日志来源为“天才搭档”，渠道为“天才搭档管理员服务”，模型为管理员 ID，usage 如实记录；用户成本记为 `0`。管理员承担费用及用户零余额可用，由返回凭据对应的现有服务额度规则实现，客户端说明不替代真实服务计费。关闭请求日志时仍有短时实际活动证据；不因仅打开窗口、读取目录或待命而伪造模型请求。模型凭据仅在本次内存中保留，不进入助手对话、工具内容、界面状态、日志或临时 Server 配置。

## 工具与真人操作

模型只获得 Hub 的受控配置工具：读取渠道/模型/客户端能力、添加或修改普通渠道、添加模型与别名、把来源模型配置到已发现客户端、修改支持的客户端参数、明确列出的批量删除、打开 Hub 相关页面、读取帮助、申请本机凭据表单。读取结果列出对应客户端支持的参数字段；配置到 Codex 时返回实际生成的独立模型别名，后续操作沿用该身份。保存沿现有配置 API，保留独立客户端副本、已有密钥和配置后改保护。

当前小分队密钥提供 `hub_squad_list_api_keys`、`hub_squad_key_options`、`hub_squad_create_api_key` 与 `hub_squad_prepare_api_key` 四项工具。只按当前账户已有权限操作，创建结果未知时沿原待确认写入机制核对，不能自动重复创建。准备导入复用站点原票据及模型目录，返回 reference / mask / settings；随后用原渠道保存和客户端配置工具完成。用户可在任一步停止或只要求读取，工具不代替用户修改已有站点密钥、组织、账户资料或支付。站点不支持导入、密钥没有绑定可导入分组、模型目录失败等原因按实际结果说明，不能编造可用模型。

没有 shell、任意文件操作、web、MCP、其他代理或任意配置路径写入。运行端使用禁用 shell 的模型目录、只读沙箱与关闭原生功能的配置；模型代理再仅保留 Hub 动态函数，所有非当前 thread/turn 的回调及其他 server request 均拒绝。此限制不影响用户自己的 Codex/天工客户端能力。

删除默认集中弹出一次本机批量确认；用户在搭档页启用“完全访问”后，可按用户指令直接执行同一受控删除流程。密钥通过界面密码表单输入，只向模型返回本次会话引用与掩码；取消表单结束此次工具等待，清空/退出/切号清除引用。普通停止撤销等待和导航，已录入的临时凭据可继续本次对话。聊天中不应发送明文密钥。

## 本机 API 与维护入口

`/api/desktop/assistant/` 提供 `GET status` 和 `POST settings {enabled?,personality?,fullAccess?}`、`send {text}`、`stop {}`、`clear {}`，另有工具路由 `confirm`、`credential`、`navigation/ack` 和 `question/answer {nonce,cancelled?,answers?}`。桌面请求需无网页 Origin 且 `x-tiancai-desktop: 1`。状态返回开关、性格、完全访问、运行端检查、登录、管理员模型、运行状态、内存消息、待删除/凭据/导航及 `pendingQuestion`；回答条目使用 `id`、可选 `optionId`／`text`。`conversationId` 仅为本次内存会话身份，`cleanupPending` 表示需要重试清理。

开关只写本机 `assistant/settings.json` 的 `enabled`，默认 `false`。不改变产品版本、用户运行中的客户端配置、安装包关联或已交付包。停用可保留运行包供本机协助共用；卸载共享 Server 需先停用两个功能且确认后台已退出，不能删用户系统 CLI。

关键源码：`src/assistant/{mod,settings,model,worker,proxy,telemetry,web,tools}.rs`，账户 transport 位于 `src/desktop/squad.rs`；可信来源/实际活动分别在 `src/desktop/request_source.rs`、`activity.rs`；顶层 daemon、HTTP 和 GUI 接线由管理会话集成。共享运行端见 `src/local_assistance/{runtime,brand,process}.rs`。
