# 天才搭档：用量与请求查询

日期：2026-11-11；适用 V1.0.25，关联 TC-023。源码已实现，必要离线检查和唯一新包状态以 [V25 交付](../releases/v1.0.25.md) 为准；真实站点与对话效果待用户验收。

用户问“今天花多少钱、用了多少 Token”时，搭档直接调用现有能力返回数字，不再只请求打开小分队页面。新增两个工具，继续由 Hub 执行，不让模型自行构造任意 API、读取请求正文或凭据。

| 工具 | 现有能力与默认范围 | 可选筛选 |
| --- | --- | --- |
| `hub_query_usage` | 默认当前已登录小分队账户、今天的实际人民币扣费及 Token/请求；`source=hub` 为本机请求库汇总 | 今天、近一周、近一月、自定日期；模型；小分队密钥/分组；本机客户端/渠道/状态；按需模型/日期分组，本机另支持客户端/渠道分组 |
| `hub_query_requests` | 默认当前小分队账户的使用记录；`source=hub` 读取本机请求列表 | 同上日期及身份筛选，`page` / `pageSize` 分页；不把当前页相加冒充总量 |

## 数据口径

- 小分队复用 `Squad::request_checked` 的当前会话认证及 `/usage/stats`、`/usage`、按需 `/usage/dashboard/models` / `/usage/dashboard/trend`。使用现成登录、账户切换检查和错误返回，不新增助手专用 POST 或真实模型测试。`today/week/month` 汇总按站点原接口默认时区与周期；自定 `startDate/endDate` 两端均包含，日期与小分队原筛选接口一致。使用记录的快捷日期沿 Hub 现有账户筛选器的系统本机日期；跨时区需要精确对齐时明确指定起止日期。
- 金额直接使用 `total_actual_cost` / `actual_cost`，按 Hub 小分队页面的人民币标识原样显示，不换汇、不把标准价 `total_cost` 或限额 `quota_used` 当实际扣费；管理员承担的搭档对话费用单列说明，不计为用户消费。
- Token 使用站点给出的总量，缓存输入单独返回，不凭模型猜计数。缺少的字段保持未知，不补零。
- 本机用量复用 `RequestLogStore::desktop_usage`，覆盖全部匹配记录，分组仍沿原接口上限。输入 Token 已归一化包含缓存，不再次叠加；缺少上报时完整总量为空，另给已上报小计和完整性标记。本机请求统计不能推导站点实际账单，`actualCost` 保持空值。
- 列表只投影时间、模型、状态/耗时、Token 和实际费用等必要元数据；不返回用户资料、完整密钥对象、管理员成本、IP、请求正文及请求头。账户切换后旧会话不能继续查询。

## 使用与表达

支持“今天花了多少”“近一周哪个模型用得最多”“WorkBuddy 今天多少次请求”“指定密钥在某两天用了多少”等组合。帮助工具列出当前统计、配置、密钥和导航能力，内置指引要求先用已有工具完成，再说明结果；不能把尚未查询说成没有能力。

默认自然简短回复，一般一至三句；比较或多项结果才用列表/小表格。内部执行日志、工具参数、身份及协议用词不直接复述给用户。三套 [性格草案](genius-buddy-personalities-draft.md) 按用户最新决定保留干练搭档、软萌猫娘、温柔女友，并约定自然使用少量 emoji；仅供用户修改审核，尚未加入产品选择，也不作为本轮已生效设置。

## 维护、回滚与验证

入口：`src/assistant/usage_tools.rs` 的参数、只读桥接、投影和汇总，`tools.rs` 注册与帮助，`mod.rs` 模块声明，`guide.md` 查询路由和默认表达。没有持久配置迁移或新的统计缓存，回滚移除该模块和注册即可，既有用量和用户数据保留。

新增离线检查使用本机合成 HTTP 服务和临时请求库，覆盖真实读取接口/筛选、实际扣费与缺失字段、分页投影、账户切换、本机全量汇总及缓存 Token 不重复相加。不会访问真实小分队、Server 或用户原始请求库，具体执行结果统一登记 V25 交付；没有将历史真实模型验收移作本批通过结论。
