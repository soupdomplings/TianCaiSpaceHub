# 天才小分队站点本机参考资料

本目录中的站点源码 ZIP 和解压目录是用户提供的本机参考资料，用于核对 Hub 与现有站点的 API、登录和账户行为。原文件保留，不作为 Hub 源码或垃圾缓存处理；除本说明外由 `.gitignore` 排除，不随 Hub 提交。

Hub 配套的可维护站点补丁位于 [integrations/tiancai-squad-browser](../../integrations/tiancai-squad-browser/README.md)，当前账户实现和部署边界见 [天才小分队账户专题](../customizations/tiancai-squad-account.md)。参考资料不构成 Hub 构建依赖，也不表示站点已经更新或部署。

如以后需要更新参考资料，仍在本机操作；不要将站点环境文件、凭据、用户数据或完整第三方仓库加入本仓库。整理流程见 [仓库清理记录](../development/repository-cleanup.md)。
