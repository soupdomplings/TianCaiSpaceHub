# 统一操作反馈（V1.0.26）

维护日期：2026-11-11。关联 TC-016、TC-017、TC-019、TC-023；本轮在 `main` 开发，由管理会话统一编译、打包与交付，不独立发布。

## 用户看到的行为

成功、失败和需要确认的操作使用共用原生组件。根据用户提供的右上角提示截图，普通操作结果显示为右上方小浮窗：绿色圆勾或红色圆叉、简短文字和关闭按钮，没有大信息条或额外通知中心。主窗口提示位于右侧内容区上沿，避开左导航和右下助手输入；模态窗口的提示放在自身右上方。提示不抢焦点，不弹系统通知，不因后台完成恢复被隐藏或最小化的 Hub。

成功和失败提示都在约 4 秒后自动收回，底部细进度条显示剩余时间；新结果重置倒计时，也可手动关闭。卡片入场和收回使用 130 ms 的 12 DIP 短位置过渡，新结果可打断旧收回并续接；减少动画直接到终态。点击提示正文或卡片空白处查看完整说明，关闭按钮只关闭提示；详情可复制，不铺在页面或按钮下。每个顶层窗口同时保留一条当前提示，新操作结果替换旧提示，不维护历史，不增加日志、通知文件或本地缓存。

V1.0.26 修复只有图标、没有正文的问题：原 `StaticText` 被设为零最小高度，横向布局居中时正文及点击区域实际高度也为零。现在只允许横向收缩，保留文字原生高度；正文、详情区域和底部进度各自保留空间。倒计时每 50 ms 更新进度，到期收回成功或失败卡片，手动关闭清除本次计时。位置动画另用私有隐藏 Panel 托管的 16 ms Timer，不与倒计时或业务轮询混派。

删除、安装、移除、清理等必要确认采用同主题窗口，给出实际动作与取消，沿原调用只确认一次。共用确认和详情窗口在首次激活时作 150 ms / 8 DIP 入场，关闭即时返回原结果；取消不执行请求，关闭后不另加确认。字段不完整等表单校验仍靠近表单；真正的运行状态、连接状态、选择数量、批量结果表格及必要执行进度保留，不把这些内容统一改成弹窗。

点击主窗口关闭按钮仍隐藏到托盘并保持后台服务运行，完全移除“已隐藏到托盘，本地服务会继续运行”的中英文提醒。隐藏到托盘或真正退出时直接关闭正在显示的操作提示并停止转场；退出时释放原生宿主和计时器，运行端及会话清理继续沿各自既有生命周期。

## 代码与覆盖入口

共用模块为 `src/gui/feedback.rs`：

| 接口 | 用途 |
| --- | --- |
| `install(frame, area)` | 指定主窗内容区域，避免提示覆盖导航、标题控制或助手输入。 |
| `success(parent, message)` / `error(parent, message)` | 按实际所属 Frame/Dialog 展示简短结果；仅在 UI 线程调用。 |
| `confirm(parent, title, message, action)` | 主题确认窗，返回一次明确选择；不发请求、不自动重试。 |
| `information(parent, title, message)` | 用户主动查看配置说明等完整内容，共用主题详情外框。 |
| `dismiss_all()` | 主窗隐藏或退出时关闭提示。 |

V1.0.25 本轮明确迁移以下入口，不用页面文字、状态值或字符串关键字猜测消息种类：

- `src/gui.rs`：共用 `show_info` / `show_error`，更新页、切换连接模式、移除 Codex 配置、删除聊天账户及日志清理确认，主窗反馈宿主与退出钩子。设置、诊断、模型目录等经这些共用函数的调用同步采用新样式。
- `src/gui/dialog_job.rs`：页内异步任务与通用保存任务的完成结果，清除重复的底部结果文字；输入校验和执行进度保留。保持草稿、按钮忙态和原一次请求，不自动重放未知写入。保存后保留的编辑窗在本窗提示；关闭的编辑窗在所属父窗提示。
- `src/gui/resources.rs`：资源操作的成功、失败及部分失败，冲突替换、共享目录、客户端移除与删除确认。批量成功项、失败项恢复入口和必要未确认状态保留，完整错误不再重复写进每个页签及选择区。
- `src/gui/tray.rs`、`text.rs`：删除关闭到托盘提醒及对应中英文字符串，保留托盘恢复和退出动作。
- `src/gui/external_import.rs`、`nvwa.rs`、`local_assistance.rs`、`tiangong_models.rs`：原显式通用确认、Dumpling 错误/配置说明/确认、共享 Server 安装确认和天工下载失败入口。批量导入的真实项目结果仍使用原三列表格。
- 客户端、WorkBuddy、天工、渠道和搭档的其他显式结果入口由同批开发接入共用 API，准确文件和构建结果以本批集成记录为准。

原生提示使用现有 `theme`、`controls::Button`、可选择文字和 DPI 换算；不引入网页、依赖或业务接口。摘要只限制显示长度，完整说明仅留当前窗口内存。提示计时器由独立 Panel 持有，避免与业务轮询共用 Timer owner。窗口销毁按自身事件清理，不因子控件销毁误清其他提示。

采用 `ui-ux-pro-max` 的定向查询 `success toast error feedback`：适用的 All 平台结果为 Success Feedback、Toast Notifications、Error Recovery 和 Error Feedback。V1.0.26 根据用户反馈统一成功和失败的 4 秒倒计时，保留手动关闭和按需详情；外观与位置沿截图及既有桌面主题，没有移植网页样式或添加重试确认流程。

小分队短请求不再创建一闪而过的等待窗：`dialog_job::run_async` 复用账户页忙态，GET 成功直接打开实际业务表单或更新原位置，写入成功及失败沿共用结果卡片。真实选择、编辑、支付和必要确认继续保留。账户异步任务也使用独立隐藏 Panel 托管 Timer，原业务 Panel 仍负责布局和反馈；不与账户轮询共用 Timer owner。完整范围与迟到结果处理见 [账户专题](../customizations/tiancai-squad-account.md#v1026-短请求等待导航与使用记录布局)。

## 兼容与回滚

无持久配置、网络接口、账号、模型来源或权限迁移。不因清理提示移除业务校验，也不改变安装确认、删除确认、写入次数或后台常驻。回退 GUI 模块及入口即可恢复原显示；已保存配置与原批量操作结果不受回退影响。
