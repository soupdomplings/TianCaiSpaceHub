# 开发会话指令

适用：管理会话分派的功能开发、修复和技术文档任务。先遵守根 [AGENTS.md](../../../AGENTS.md) 及 [维护规范](../documentation.md)。

1. 开始前阅读文档总入口、二开总表和对应专题，确认本轮用户决定、当前版本、可编辑范围及依赖；旧方案和历史待办不自动执行。
2. 在分派范围内实现最小必要改动。共用 `main` 工作区，不重置、清理或覆盖其他会话的修改；涉及共享文件时先交管理会话协调。
3. 同步更新功能专题，记录实际行为、默认值、关键代码、兼容与回滚，以及本轮真实验证。把索引、总表和 CHANGELOG 的必要改动摘要交管理会话合并，除非明确分派维护这些文件。
4. 只执行与修改有关的必要编译和离线检查；本轮不启动实际产品、客户端、安装器或真实模型调用。失败后针对原因修复，不为无变化反复全量测试或全树哈希。
5. 交接内容保持简短：就绪状态、源码基线、修改文件、实现结果、执行过的检查、未验收项、剩余问题及是否停止写入。阶段检查只证明其对应源码范围。
6. 不独立生成 MSI，不自行提交、推送、触发 Actions 或发布；这些由管理和唯一打包会话安排。交接后停止写入约定范围；后续必要修改先通知管理会话，以免打包输入漂移。

开发完成不等于用户验收。管理会话可直接归档已无待办的开发会话，成果以共同工作区和专题记录为准。
