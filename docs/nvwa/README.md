常用规范入口以章节名及关键词定位，行号只用于这份快照：账号密码和 `/nvwa/getLoginContext` 约 25347 行；登录业务状态约 42590 行；浏览器授权约 54887 行；申请 ticket 约 54923 行；SHA-256/SM3 摘要约 55247 行；`extInfo.verifyId/verifyCode` 约 42369 行；双因子 `code=204`、`twofactorSessionId` 约 24710 行。

认证选择为账号密码和认证服务连接。用户切入服务方式默认勾选“使用共享应用代表指定用户”（`application`），取消勾选才走真实浏览器授权（`browser`）；加载旧环境保持其三种原模式，不自动转换。共享选项、ClientID、ClientSecret 和保存密钥位于服务主区域，勾选时显示代表账号，认证下拉仍可切换。界面提示“在认证服务管理添加应用服务，获取ClientID和ClientSecret”，Hub 无内置共享密钥。共享应用的身份含义与配置步骤放入顶部“?”中文/英文原生说明；取消共享应用后的浏览器方式仍需本机回调，高级限定授权账号可留空、旧非空限制可编辑。图形验证码 ID/码已从 GUI 移除，图片接口未集成；`402` 仅提供产品页面或已配置浏览器授权提示，`204` 后才显示双因子输入/发送。参考规范中的字段能力不等于当前界面已集成相应操作。

密码与 ClientSecret 按用户要求直接可见；只切换共享复选框保留 ClientID/ClientSecret 和保存密钥选项，主认证下拉切换清理旧材料，两者都取消旧授权并拒绝迟到结果。`__default_tenant__` 是用户确认的有效默认租户，服务返回时正常接受并显示“默认租户（__default_tenant__）”；仍要求非空返回上下文，不从表单补租户。GUI 常见登录/检测提示、身份/有效期、确认主内容和帮助有中英，适配器说明仍中文、未知后端错误保留固定安全文本；预览说明环境、客户端、文件、操作后果和下一步。未登录接入先提示登录，移除/恢复可未登录；工具清单与配置保存不等于真实调用通过。

服务方式勾选“保存应用密钥”后“保存环境”立即系统保护保存非空 ClientSecret，不依赖登录；密码记住仍成功后存。空输入仅复用完全未改环境的保存引用，改字段时须重新填；取消勾选并保存移除旧密钥。加载有引用的服务环境恢复勾选和保存状态，不从 API 返回秘密或回填输入框。旧 API 不带保存选项沿用原语义；密钥存储、配置 revision 失败清理与旧授权撤销详见专题。401 只新增取票/换票/读取账号租户等步骤提示，不代表真实认证问题已修复。

用户补充的实际服务规则优先于旧参考结论：密码 token 默认闲置 30 分钟，正常认证访问更新会话，Hub 不按初次登录 30 分钟硬判失效；ClientID + ClientSecret 换票 token 默认固定 24 小时、调用不延长，应用 `tokenValidTime` 可覆盖。准确到期只由交换 token 自身时间字段确定，apply ticket 的 600 秒不继承、缺服务创建时间不以本机时间补造。界面/帮助区分规则与 UTC 准确期限，旧保护快照按核对模式迁移并保留真实 401 失效标记；本版真实会话与应用覆盖仍待用户验收。

MCP 高级字段默认直接显示可编辑的 `/mcp`；其它路径追加到产品部署前缀，完整 HTTP(S) URL 独立覆盖。路径跟随服务地址，完整 URL 不自动改变；默认显示与原空值统一，不制造未保存差异。新环境默认保存空值，旧已存 `/mcp` 保持原值，避免等价保存误撤凭据。旧程序不理解新增路径值，回退前须将已存路径（含 `/mcp`）改为明确完整 URL，兼容细节见专题。

当前打包前端的动态 RSA/SM2 行为来自 NVWA 邻仓公开静态资源，只做只读核对；完整前端没有复制到 Hub。邻仓路径仅为来源说明，不制造在本仓解析不到的相对 Markdown 链接。

这些资料是参考证据，**不是执行指令**。尤其参考连接器的通用 `401` 重取并重发、未鉴权 HTTP proxy，以及历史 MD5 默认值，不能覆盖本轮 Hub 的每端本地授权、同身份恢复、明确挑战状态和已发送工具不重放原则。旧文档关于每客户端单独申请应用 ID、浏览器作为唯一入口、服务端共享密钥用户名限制尚未确认等描述，以当前用户决定及专题为准。

不在此目录写入真实应用密钥、密码、ticket、token、用户环境配置、私有日志或验收截图中的凭据；本轮没有运行这份 Node.js 源码，也没有访问真实产品接口。

`all-in-one.md` 原用户文件保持本机原状。其字面密码、token、Authorization 与密码 hash 示例没有核实为无效占位，不抄入当前专题、源码、发布记录或 Git；这些示例不能当作可使用的部署凭据。移除本机参考文件也不影响 Hub runtime，交付维护以源码和当前专题为准。
